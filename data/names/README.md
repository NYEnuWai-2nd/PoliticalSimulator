# キャラクター名データ

| ファイル | 内容 |
|---|---|
| surnames.json | 姓499件。漢字、読み、ローマ字、出現の重み（上位100は頻度順位に基づく） |
| given_names.json | 名6029件（男性1924、女性4105）。性別、名の型、生まれ年代（1940〜2010年代）ごとの重み |
| exclude_real_politicians.json | 実在の国会議員と完全一致する氏名（漢字5176、読み5028）のSHA-256。氏名そのものは含まない |
| nameGenerator.js | シード固定の名前生成器（ブラウザ、Node.js両対応のESモジュール） |
| LICENSE-NOTICE.txt | 元データ（willnet/gimei、faker-ruby/faker、どちらもMIT）のライセンス表記 |

名の型は「昭和前期型」「昭和後期型」「平成型」「汎用」の4種類で、語尾などの規則で機械的に分けています。
生まれ年代ごとの重みは style_weights で調整できます。
