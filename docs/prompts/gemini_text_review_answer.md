## 1. 全体の評価

### 良いところ
1. **複雑な政治要素を育成ゲームの形式にうまく落とし込んでいる**
   能力値、経験点、特殊能力（コツ）、やる気、体力といった育成ゲームの仕組みが、政治活動（地元回り、街頭演説、政策勉強会など）と自然に結びついている。さらに「遊び方」やツールチップ、秘書の助言によって、初めて遊ぶ人にも手順やルールが直感的に伝わる構成になっている。
2. **立場や場面に応じた呼び方と口調の書き分けが丁寧**
   地の文や肩書きでは「首相」、会話の呼びかけでは「総理」、正式な就任場面では「内閣総理大臣」と使い分けられており、プレイヤーが首相になると秘書の呼び方も「先生」から「総理」に変わるなど、役職の上昇が実感できる書き方になっている。
3. **政策テーマを扱ううえで政治的な偏りがない**
   選択的夫婦別姓、防衛力強化、原発再稼働、減税、子育て支援などの現実的なテーマを扱いながらも、どの法案に対しても「賛成しやすい立場／反対しやすい立場」を淡々と並べるにとどめており、特定の思想を善悪として扱う偏りが見られない。

### 全体に共通する問題
1. **書き方の決まり（特に「格助詞直後の読点禁止」と「直接的な表現」）の遵守漏れ**
   全体の多くがルールに沿って書かれている一方で、`life_events`、`events`、`game/career`、`app/views` に「〜が、」「〜に、」「〜で、」「〜から、」「〜と、」の直後に読点が入った文が約20件残っている。また「船出した」「台所事情」「収入が細い」など、比喩的・感覚的な表現も一部に残っている。
2. **内部表現やシステム上の文字列がそのまま画面・セリフに出ている**
   「がが少ない（休養を）」（文字列連結の誤り）、「市場重視寄り」（「重視」と「寄り」の重複）、「始め方の最初の画面」「与党の自党」「赤特」「JSON として読めない」など、開発側の用語や処理都合がそのまま表に出てしまい、意味が分かりにくくなったり会話の調子が不自然になったりしている箇所がある。
3. **用語・文体（常体と敬体）・文末句点の細かな不統一**
   ゲーム全体でそろえられているはずの言葉に「党の幹部／執行部」「党首／総裁」「政策勉強会／勉強会」「内閣支持率／支持率」「議員人生／政治家人生」「たまる／貯まる」といった揺れがある。また、UI説明文は常体で統一されている中に1か所だけ敬体が混ざる箇所や、エラーメッセージで末尾の句点が抜けた箇所がある。

## 4. 確認したいこと

1. **`game/game:389` の「任期満了。総選挙は次の段階で実装します。」について**
   `game/game:390` に本実装用と思われる「衆議院議員の任期が満了した。」がある一方で、同じファイルに開発中の仮メッセージが残っています。議員人生モードで表示される経路がないか確認してください。
2. **`app/views:179` の「がが少ない（休養を）」の直前の文字列**
   コード上の連結のしかたによって、修正案を「少ない（休養を）」にするか「体力が少ない（休養を）」にするかが変わるため、直前に何が結合されているか確認してください。
3. **`bills-1` の「2026年度予算」という固定の年号**
   `game/game:90, 162, 349, 384` では `{budgetYear}年度予算` と年が動的に変わる作りになっていますが、`bills-1` のデータだけは「2026年度予算」と固定文字になっています。2027年以降のゲーム進行中でも、この文がそのまま出ないか確認してください（`billName` 関数等で差し替えられていれば問題ありません）。
4. **`game/game:363` の「石橋内閣は総辞職した。」の分岐条件**
   `365` に「内閣不信任案が可決され、内閣は総辞職した。」という汎用文がありますが、石橋内閣のあとに別の内閣へ代わった後で誤って `363`（石橋内閣）が出ないか確認してください。
5. **`game/game:339` の「（支持率 −2）」の数値ハードコード**
