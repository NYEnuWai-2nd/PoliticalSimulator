# 3. 全体の傾向

作る側（AI）が繰り返している不自然な言い方の癖を5点にまとめました。

1. **カタカナを避けて和語にしようとした結果の「説明的な造語」**
   ルート・バー・ゲージ・セーブデータなどの語を使わずに表現しようとして、「出馬の道」「比例名簿の道」「情勢の棒」「状態の帯」「地盤の進み具合」「保存している続き」「大事なこと」といった、日常でもニュースでも他ゲームでも使われない奇妙な名詞句が繰り返し生まれています。カタカナを避ける場合でも、「方法」「グラフ」「情報欄」「プレイ状況」「主な記録」など、日本語として定着している言葉を選ぶ方が自然です。

2. **ゲーム内部の変数名や仕様を、地の文やキャラクターのセリフに直接持ち込む癖**
   「知名度型」「行政型」「汎用」「安定派」「資金の能力」「資金の経験点」「発信を見た人」「揺らぎを除いた見込み」「出来事の弁舌の判定」「再分配を重んじる野党は（原発再稼働に）強く反対する」など、設計上の分類名や計算パラメータがそのまま文章に露出しています。また、秘書の助言でも「{…}%の確率で倒れます」「20を切ると」「25を切ると」「経験点の伸びが鈍るので」と、生身の人間ではなくゲームシステムがルールを解説するような口調になっています。

3. **同じ名詞の重複・動作と名詞のミスマッチ・分類軸の不揃い**
   - 所持金・能力名・経験点名の3つすべてに「資金」が使われており、「資金の能力が高いほど」のような不自然な文を生んでいます。
   - 「対案の準備をためる」「選ぶ物語はありません」「選んだこと」「家系：なし」など、動作や名詞の組み合わせが噛み合っていない箇所が目立ちます。
   - 「小選挙区 / 引退する現職の後継」「新人 / 世襲・名門」のように、同じグループの選択肢なのに分類の観点がズレて重複・矛盾している箇所があります。

4. **全国47都道府県を対象にしながら「県」「県議」で固定してしまう癖**
   「地元の県」「赤い太枠の県」「県議と連携」「県議団」「県議会議員」「県庁」「県政」など、すべて「県」前提で書かれているため、東京都・北海道・大阪府・京都府を選んだプレイヤーには事実と矛盾する違和感が生じます。「都道府県」「地方議員」「地方議会」に揃える必要があります。同様に、大臣だけでなく党役員や「影の大臣」の仕事まで「公務」で一括りにしてしまっています。

5. **他ジャンルのゲーム用語と、突然混ざる古風・翻訳調の比喩**
   「特殊能力（金・青・赤・緑）」「コツLv」「経験点を払う」「特殊能力が外れた」「上位の能力に置き換わった」「同じ世界で」「地盤UP」「チャリン!」など、育成ゲームやRPG由来の表現が硬派な政治の文脈で浮いている場面があります。一方で物語文には、「告ぐ」「知りて」「主従の線引き」「十字架を背負った」「ドブ板の絆」「清潔な姿勢」「政治への情熱が燃えた」のように、唐突に時代がかった文語や大げさな翻訳調の比喩が混ざる癖が見られます。
