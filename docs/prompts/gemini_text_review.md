# Gemini に頼む：ゲームの中の文章の確認

使い方：`docs/prompts/gemini_text_review_texts.md`（ゲームの中の文章のうち、Gemini が書いていない分を抜き出したもの）を Gemini に添付し、下の「プロンプト」以下を貼る。返答は `docs/prompts/output.txt` に貼るかこのチャットに添付すれば、Claude が元の場所を探して直す。

抜き出しは作業用のスクリプトで行った。データ（data/game/*.json）は画面に出る文字列だけ、コードは画面・記録・助言に出る文字列だけを集めた。Gemini が前に書いた分（活動のあとの短い文、日常の出来事の60件、法案の16件、政局の出来事の20件、物語の連作）は含めていない。

---

## プロンプト

日本を舞台にした政治シミュレーションゲーム「議員人生」の、ゲームの中の文章を確認してください。添付の `gemini_text_review_texts.md` に、画面や記録に出る文を約1000件、表にしてあります。

### ゲームの説明

- 一人の政治家として、新人候補から当選を重ね、役職を上り、首相を目指す。毎月1つ活動を選ぶとひと月進む。野球ゲームの育成モード（能力のランク、特殊能力、毎月の練習の選択、出来事の会話）に近い遊び方。
- 政党と人物は架空で、地名は実際の都道府県名を使う。議会は一院制。
- 画面はスマホと PC の両方で遊ぶ。ボタンや札の文字は短くないと収まらない。
- 文章を書いた人（Claude）は、次の書き方の決まりで書いている。この決まりに合っているかも見てほしい。
  - 比喩より直接的で説明的な語を使う。
  - 読点は格助詞（が、を、に、で など）の直後には打たない（列挙の場合を除く）。
  - 助詞、助動詞、接続詞の使い方に注意する。

### 表の読み方

- 「番号」で場所を示す。データは `ファイル名-連番`（例：`career-3`）、コードは `ファイル:行`（例：`game/career:485`）。コードは同じ行に複数の文があることがある。
- `{ }` の中は、遊ぶときに数や名前に置き換わる部分。`{…}` は、条件によって別の文が入る部分（その文は近くの行に別に載っている）。
- `⏎` は改行。

### 見てほしいこと

1. **日本語の誤り**：誤字、助詞の誤り、文法の崩れ、主語と述語のねじれ。
2. **不自然な言い回し**：意味は通るが引っかかる文、機械的・翻訳調の文、回りくどい文。
3. **用語の不統一**：同じものを別の言葉で呼んでいるところ（例：「党の幹部」と「党執行部」、「浪人」と「落選中」）。どちらにそろえるべきかも書く。
4. **分かりにくさ**：初めて遊ぶ人に意味が伝わらない説明、ボタンの文として何が起きるか分からないもの。
5. **調子の不一致**：秘書のセリフ、記録の文、画面の説明で、口調や敬語の段階がぶれているところ。
6. **政治的な偏り、実在の人物・事件・作品を連想させすぎる表現**、特定の属性の人を笑いものにする表現。

### 守ってほしいこと

1. `{ }` の中身と、その位置関係（何が入るか）は変えない。置き換わる部分の前後の文だけを直す。
2. 数値や仕組みの説明は、意味を変えない（例：「12下がるごとに1つ下がる」の数を変えない）。仕組みの説明が誤っていそうなら、直さずに「確認したい」として挙げる。
3. 政党名、役職名（幹事長、影の大臣など）、能力名（弁舌、政策、調整、知名度、組織、資金）、特殊能力の名前は、明らかな誤りでなければ変えない。
4. ボタン、タブ、札の短い文は、元の文字数を大きく超えない。
5. 直す必要のない文は挙げない。好みの差だけのものは挙げない。
6. 日本語で答える。

### 出してほしいもの

1. **全体の評価**：良いところと、全体に共通する問題を3つずつ。
2. **修正案の表**：直したほうがよい文だけを、次の列の表で。重要なものから順に並べる。

   | 番号 | 元の文 | 修正案 | 種類 | 理由 |
   |---|---|---|---|---|

   「元の文」は表のとおりに写す（コードは同じ行に複数の文があるので、どの文かをこれで見分ける）。「種類」は「誤り」「不自然」「不統一」「分かりにくい」「調子」「偏り」のどれか。
3. **用語をそろえる表**：ゲーム全体でそろえたい言葉の一覧（今ばらついている言い方と、そろえる先の言い方）。
4. **確認したいこと**：仕組みの説明が誤っていそうなところや、文だけでは判断できないところ。

出力は Markdown の見出しと表でまとめてください。修正案が多い場合は、途中で切らずに続けて出してください。
