# Gemini に頼む：用語と文章の「日本語としての自然さ」の確認

使い方：次の2つのファイルを Gemini に添付し、下の「プロンプト」以下を貼る。返答は `docs/prompts/output.txt` に貼るかこのチャットに添付すれば、Claude が言い換えを決めて直す（迷うものはユーザーに確認する）。

- `gemini_naturalness_terms.md`：画面に出る用語の一覧（約70項目。意味、出る場所、出どころ付き）。Claude が手で作った。
- `gemini_naturalness_texts.md`：ゲームの中の文章の全部（約2250件）。前回の文章の確認（`gemini_text_review.md`）と違い、Gemini が書いた分（日常の出来事、法案、政局の出来事、活動のあとの短い文、物語）も含む。作業用のスクリプトで抜き出した。

前回の確認は、誤り・表記の揺れ・書き方の決まりを中心に見たので、「その言葉自体がふつう使われるか」はほとんど見ていない。今回はそこだけを見る。

---

## プロンプト

日本を舞台にした政治シミュレーションゲーム「議員人生」の、画面の用語と文章が「日本語として自然か」を確かめてください。添付は2つです。

- `gemini_naturalness_terms.md`：画面のボタン、タブ、見出し、数値の名前に使っている用語の一覧。番号、出る場所、意味、出どころ（作る側の造語か、本物の政治の言葉か、ほかのゲームに寄せた言葉か）が付いています。
- `gemini_naturalness_texts.md`：ゲームの中の文章の全部（約2250件）。番号で場所を示します。`{ }` の中は遊ぶときに数や名前に置き換わる部分、`{…}` は条件で別の文が入る部分、`⏎` は改行です。

### ゲームの説明

- 一人の政治家として、新人候補から当選を重ね、役職を上り、首相を目指す。毎月1つ活動を選ぶとひと月進む。野球ゲームの育成モード（能力のランク、特殊能力、毎月の練習の選択、出来事の会話）に近い遊び方。
- 遊ぶ人は、政治に詳しくない人から詳しい人まで。スマホと PC で遊ぶ。ボタンや札の文字は短くないと収まらない。
- 用語の多くは、作る側（AI の Claude）が、仕組みを一言で表そうとして名付けた。そのため、説明的すぎる言い方や、ふつうは使わない造語が混じっているおそれがある。今回はそれを見つけたい。

### 見てほしいこと

1. **ふつう使われない言葉・造語**：新聞、テレビのニュース、政治家の話し言葉、ほかのゲームのどれでも、ふつうは使わない言葉や組み合わせ。例：「出馬の道」「経歴類型」「地盤の進み具合」「間柄の札」のような、説明のために作ったような言い方。
2. **説明的すぎる・回りくどい言い方**：もっと短く、ふつうの言い方があるもの。
3. **本物の政治用語だが、ふつうの人には分かりにくいもの**：消すのではなく、残したうえで説明を添えるべきものとして挙げる（例：国対委員長、党議拘束、比例復活）。
4. **ほかのゲームの言葉で、このゲームでは浮くもの**：育成ゲームに寄せた言葉（やる気、経験点、コツ、特殊能力など）は、意図して使っている。それでも政治の場面で不自然に感じるものがあれば挙げる。ただし、作品名やキャラクター名を出して比べない。
5. **硬すぎる・翻訳調・AI が書いたように感じる言い回し**：文章の中で、人が書くとこうは書かない、と感じるもの。

### 守ってほしいこと

1. 用語は、言い換えるならゲームの中でずっと使える言い方にする（同じものを指す言葉を1つに決める）。ボタンや札の言葉は、元の文字数を大きく超えない。
2. 本物の政治用語は、正しく使われていれば言い換えない（説明を添える案にする）。
3. `{ }` の中身と位置は変えない。数値や仕組みの意味も変えない。
4. どの政党、政治的立場にも肩入れしない言い方にする。
5. 好みの差だけのものは挙げない。前回の確認ですでに直した、読点の位置や表記の揺れは対象にしない。
6. 日本語で答える。

### 出してほしいもの

1. **用語の判定表**：`gemini_naturalness_terms.md` のすべての番号について、次の表で。

   | 番号 | 用語 | 判定 | 言い換えの案 | 理由 |
   |---|---|---|---|---|

   「判定」は次のどれか。
   - 「そのまま」：ふつうに通じる。
   - 「説明を添える」：本物の言葉で正しいが、初めての人には分かりにくい。説明の文の案を「言い換えの案」の列に書く。
   - 「言い換える」：不自然、造語、説明的すぎる。言い換えの案を2つまで、よいと思う順に書く。

2. **文章の中の不自然な言葉の表**：`gemini_naturalness_texts.md` の中で、上の「見てほしいこと」に当たるものだけを、次の表で。重要なものから順に。

   | 番号 | 元の文 | 気になる言葉 | 修正案 | 種類 |
   |---|---|---|---|---|

   「元の文」は表のとおりに写す（同じ番号に複数の文があることがあるため）。「種類」は「造語」「説明的」「分かりにくい政治用語」「浮いたゲーム用語」「硬い・翻訳調」のどれか。

3. **全体の傾向**：作る側が繰り返している不自然な言い方の癖を3〜5個。たとえば「〜の道」「〜の札」のように、同じ形の造語がくり返されている、など。今後の文章を書くときの注意として使う。

出力は Markdown の見出しと表でまとめてください。量が多い場合は、途中で切らずに続けて出してください。
