# UI デザイン仕様（Gemini の出力の控え）

Gemini が、野球育成ゲームの画面の参考画像を分析してまとめたデザイン仕様の文章部分を控えたもの。もとの出力は `docs/prompts/output.txt` に貼られていたが、その後アイコンの出力で上書きされたため、文章部分をここに残す。テンプレートの HTML 本体は `docs/prompts/ui_template.html` にある。

このゲームでは、色や部品の形だけを参考にする。元になったゲームのキャラクター名、モード名、作品名、キャラクターの絵は使わない（CLAUDE.md の「決まったこと」）。

## 1. デザインの5つの決まり

### ① 色の使い分け（意味と色を結び付ける）

| 用途 | 基準の色（HEX） |
|---|---|
| 背景 | `#DFF5FC` → `#AEE5F7` → `#73CEF0` のシアンのグラデーションに、白の斜めの多角形を透かして重ねる |
| システムの帯（上下の帯、吹き出しの背景） | `#0B2242`、`rgba(10, 38, 72, 0.88)`。境界線は `#4AD0FF` |
| 選んでいるボタン・カーソル | 背景 `#FFE566` → `#FF8800`、外枠 `3px solid #E61E1E`（赤の太枠） |
| 能力のランク（S〜G） | S `#FF55CC`（または金 `#FFB800`）、A `#E61C7A`、B `#E02020`、C `#F26400`、D `#D9A000`、E `#17A63B`、F `#1D78E8`、G `#7D8694` |
| 名札の色（元のゲームでは守備位置） | `#FF8AA6`、`#67DDFF`、`#FFE052`、`#7BEE74`（複数のときは斜めに塗り分ける）。このゲームでは政党の色に置き換える |
| 特殊能力のチップ | 青 `#8AE3FA`（枠 `#1A84C6`）、赤 `#FF9E9E`（枠 `#CC2929`）、金 `#FFD645`（枠 `#C47B00`）、緑 `#7CEB94`（枠 `#1E9E3B`）、赤青の混合は左が水色・右が桃色の斜めの塗り分け |

### ② 2段の光沢と太い縁取りの文字

ボタン、特殊能力のチップ、タブは平たい塗りにしない。上半分が明るく、中央（48〜52%）で色が少し切り替わる、プラスチックのような光沢のグラデーションにする。ランクの文字、見出し、増える数値（`+35` など）には、白か紺の太い縁取り（`text-shadow` や `-webkit-text-stroke`）を付け、背景の情報が多くても読めるようにする。

### ③ いつも表示する状態の帯

育成の画面や会話の画面では、画面の下に「時期・体力のゲージ・やる気の顔・所持金」の帯をいつも出す。会話の途中でも、プレイヤーが今の状態を見失わないようにするため。

### ④ 左のメニューと右の詳しい一覧

一覧や設定の画面では、左に縦に積んだ立体的なボタンのメニュー（OK、変更する、キャンセルなど）を置き、右にタブの切り替えと、行の詰まった一覧を置く。

### ⑤ 機種ごとの組み替え

- 家庭用ゲーム機（16:9）：左右に広く使い、横に並べたカードや2列の能力表を出す。
- 携帯ゲーム機（4:3〜16:9）：原色と太い黒の縁取り、点を並べた枠、簡単なアイコン（ハート、ゲージ）で画面を詰める。
- スマホアプリ（9:16）：左右に並べるのをやめ、経験点と仲間の評価を縦に積み、下に親指で押せる丸いボタンを置く。

## 2. テンプレートの7画面

`docs/prompts/ui_template.html` を参照（01 モード選択、02 育成の練習、03 会話と選択肢、04 能力の詳細、05 左メニューと一覧・進行カレンダー、06 一覧と確認ダイアログ、07 スマホ縦画面）。CSS は「1. 色などの定義」「2. 共通の部品」「3. 画面ごと」に分かれている。

## 3. 組み込みの指針

1. Web で作る場合は、テンプレートの `<style>` のうち「1. DESIGN TOKENS」と「2. COMMON COMPONENTS」を CSS ファイルとして切り出して読み込めば、ボタン（`.pp-btn`）、特殊能力のチップ（`.ab-chip`）、名札（`.pos-badge`）、確認ダイアログ（`.pp-modal-box`）などの部品をそのまま使える。このゲームでは名前を自分たちのものに付け替える。
2. 選んでいるボタンには「橙〜黄の縦のグラデーション」と「赤い枠（`#E61919`、3px）」を当てる。これだけでコントローラーで選んでいる感じが出る。
3. 細かい画面を足すときは、05 の「左メニュー＋右のタブ＋行（`.roster-row`）」の形を流用し、行の列を増やして作る。
