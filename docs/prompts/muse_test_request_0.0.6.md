# Muse への試行の依頼（v0.0.6-alpha：連立の作り直しと、中規模・小規模の党の道）

使い方：0.0.6-alpha の変更をプッシュしてから、下の「依頼」以下を Muse に渡す。

---

## 依頼

議員人生モードの v0.0.6-alpha を試して、レポートをください。前回の試行（中規模政党の政権獲得試行と連立の計算、第7版のプレイレポート）で分かった問題に手を入れた版です。特に「民政党と民権党以外の党でも、30年の中に山場があるか」を測ってほしいです。

### 試す版

- CLI を再ビルドして試してください（`npm run build:cli`、`node cli/seiji.mjs`）。起動直後の1行（JSON なら `"type": "ready"`）の版が **v0.0.6-alpha** で、コミットのハッシュが最新であることを確かめてから始めてください。
- 公開版（GitHub Pages）の始め方の画面にも、同じ版とハッシュが出るはずです。

### 前回からの主な変更

1. **連立の組み方を作り直した**（`src/game/politics.ts` の `formCoalition`、数値は `data/game/politics.json` の coalition）
   - 前は「思想の近い党から順に、過半数に届くまで最大2党」だった。今は、思想の距離が2.5以内で、中心の党の議席の半分より少ない党を最大3党まで足した組み合わせを全部作り、過半数に届くものから選ぶ（加わる党が少ない → 第一党が中心 → 思想の幅が狭い → 過半数を超えすぎない）。
   - 第一党を中心にしても、今の与党に党を足しても届かないときは、**第一党を除いた連合**（最大7党、思想の幅3.2まで）を作る。首相は連合の中で思想の真ん中にいる党から出す。
   - 閣僚は、連立相手の議席の比で配る（どの連立相手にも少なくとも1つ）。
2. **任期の途中の連立の離脱**：内閣支持率が低いほど、連立の党が多いほど、第一党を除いた連合ほど、連立相手が抜けやすい。与党が大きく割れれば、総選挙を待たずに連立を組み直す。
3. **首相の短命による逆風**：同じ政権のまま首相が続けて替わると、内閣支持率が戻る基準が下がる。
4. **連立の場面**（プレイヤーが自分の党の党首のとき、総選挙のあとに出る。物語と同じく `status` にセリフと選択肢が出て、`choose <番号>` で選ぶ）
   - 連立に誘われる（`coalition_offer`）：1 加わる／2 閣外から協力する／3 断る
   - 第一党を除いた連合で首相の党になる（`coalition_pm`）：1 引き受ける／2 別の党に譲る
   - 野党で、第一党を除いた連合が組める（`coalition_call`、与党が過半数を保っていれば `coalition_call_hard`）：1 各党に呼びかける（調整の判定。50か70）／2 見送る。通ると呼びかけた党の党首が首相になり、続けて `coalition_pm` が出る
5. **始め方の案内**：小選挙区の議席が5未満の党（公正党、集産党、れいめい、参画党など）は、比例単独で出るほうが当選しやすいと案内する。
6. そのほか（0.0.4〜0.0.5）：物語の連作21本（うち4本は上の連立の場面）、人物との関係と間柄の札、用語の言い換え（持ち味、きっかけ、資金力、職務など）、県議の表記の出し分け、セーブの形4。

### 試してほしいこと

#### A. 全政党の試行（いちばん大事）

前回の「全政党・首相到達試行」と同じ形で、議席のある全政党（民政、民権、刷新、協和、公正、れいめい、集産、参画、保守会議、社平）をそれぞれ30人生以上、30年通しで回してください。

- 開始条件：各党の一番強い始め方。小選挙区の議席が5未満の党は **比例単独** で始めてください（今回の案内どおり）。
- 方針：党首選には毎回立候補する（`run on`）。連立の場面は次の2通りで回し、比べてください。
  - 方針1：いつも1番目（加わる、引き受ける、呼びかける）
  - 方針2：場面ごとに乱数で選ぶ
- 記録してほしい段階（前回と同じ）：①自党が政権与党に入る ②自党が政権の中心（首相の党）になる ③本人が首相になる。あわせて、本人が党首になった人生の数。
- 前回の結果（v0.0.3、刷新・協和は政権入り0/60、公正党は主導0/60、首相はどれも0/60）と並べてください。

#### B. 政局の動きの量

全政党の試行の中から、次を数えてください。

- 政権交代（与党第一党の交代）の回数（30年あたり）
- 第一党を除いた連合ができた回数と、その顔ぶれ、首相の党
- 連立の離脱の回数と、総選挙を待たない連立の組み直しの回数
- 少数与党になった総選挙の割合
- 第一党の最大・最小議席（極端な大勝や、議席がほぼ消える党が出ていないか）

「政権交代が多すぎて落ち着かない」「第一党を除いた連合ばかりになる」のように、現実離れした動きがあれば教えてください。

#### C. 連立の場面の手触り（2人生くらいを丁寧に）

協和党か刷新で党首を目指す人生を2つ、場面ごとに選択を変えながら遊んでください。

- 場面の文と選択肢は分かりやすいか。選んだ結果（政権の顔ぶれ、自分の役職、閣僚の配分）が、文のとおりになっているか。
- 「閣外から協力する」「断る」「首相を譲る」を選んだあと、政局がどう動いたか。
- 中規模の党の首相は、簡単すぎないか、難しすぎないか。首相になったあと、連合はどのくらい続いたか。

#### D. ついでに確かめてほしいこと

- **古いセーブの読み込み**：v0.0.4-alpha 以前のセーブ（形が3以前。能力が「資金」の名前だったもの）を持っていれば、読み込んで続きが遊べるか（能力が「資金力」に付け替わるか）。前回は実データで確かめていなかったので。
- **県議の表記**：東京・北海道・大阪・京都で始めたとき、都議・道議・府議と出るか。
- **クラッシュや止まる場面**がないか。あれば、シードと手順を書いてください（前回の党首選の不具合は直してあります）。
