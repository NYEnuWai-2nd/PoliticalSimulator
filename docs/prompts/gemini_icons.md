あなたは、ブラウザで動く日本の政治シミュレーションゲーム用に、オリジナルのアイコン一式を SVG で作ります。プレイヤーは架空の政党の新人候補から始めて、選挙に勝ち、議員として出世していきます。画面は、野球育成ゲームのような明るくポップな見た目（シアンの背景、紺の太い縁取り、上半分が明るい光沢のあるボタン）で、PC とスマホの両方で遊びます。

## アイコンの要件

1. すべて SVG で、`viewBox="0 0 64 64"` にそろえる。PC では 32〜48px、スマホでは 24〜40px で表示するので、24px でも何の絵かわかる単純な形にする。
2. 絵柄の決まりをすべてのアイコンでそろえる。
   - 輪郭は紺（#0b2447）の太い線（stroke-width 4前後、stroke-linejoin と stroke-linecap は round）。
   - 塗りは平たい色に、上半分だけ少し明るくする光沢（白の半透明の形を重ねる程度）。グラデーションは使ってもよいが、`<defs>` の id がアイコン同士でぶつからないよう、id にはアイコン名を前に付ける（例：`act-local-gloss`）。
   - 色は下の色見本から選ぶ。
3. オリジナルの絵にする。次のものは描かない。
   - 既存のゲームのキャラクター、ロゴ、マーク（野球帽に文字の入った主人公などを含む）
   - 実在の政党のロゴやシンボルマーク、実在の人物の顔、実在の新聞社やテレビ局のロゴ
   - 政府や皇室の紋章（菊の紋、桐の紋など）、国旗をそのまま主役にした絵
   - 文字（漢字・かな・英字）。ただし「¥」記号と数字はよい
4. SVG には `<script>`、`<image>`、`<foreignObject>`、外部ファイルやフォントの読み込み、`on〜` で始まる属性を入れない。1つのアイコンは2KB 以内を目安にする。

## 出力してほしいファイル

### 1. `icons.js`（ES モジュール、外部ライブラリなし）

```js
// アイコン一式（すべて viewBox="0 0 64 64"）
export const ICONS = {
  "act-local": `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">…</svg>`,
  // …
};

/** アイコンの種類ごとの id の一覧（act, exp, ab, field, tab, st, gov, ev） */
export const ICON_GROUPS = { act: ["act-local", …], … };

/** id のアイコンを、指定した大きさの <svg> 文字列で返す。aria-label に label を入れる */
export function iconSvg(id, size = 32, label = "") { … }
```

- 上の表のすべての id を含める。省略や「以下同様」は不可。
- `iconSvg` は、ICONS の SVG の `width` と `height` を size にし、`role="img"` と `aria-label` を付けて返す。存在しない id のときは灰色の四角を返す。

### 2. `icons_preview.html`

`icons.js` を読み込み、グループごとに見出しを付けて、全アイコンを 64px と 24px の2つの大きさで並べる確認用のページ。背景はシアンの明るい色（#e6f7fd）と紺（#0b2447）を切り替えるボタンを付ける。各アイコンの下に id を表示する。

## そのほかの指定

- コード中のコメントは日本語で書く。
- 最後に、描くのが難しかったアイコンと、表の内容から変えたものがあれば短く説明する。検査（id がそろっているか、禁止したタグがないか）はこちらで行うので、検査に通ったと推測で書かなくてよい。
