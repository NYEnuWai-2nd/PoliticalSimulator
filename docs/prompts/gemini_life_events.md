# Gemini に頼む：議員人生モードの「日常の出来事」のアイデア出し

使い方：下の「プロンプト」以下をそのまま Gemini に貼る。出力（JSON）は `docs/prompts/output.txt` に貼れば、Claude が中身を確かめて `data/game/life_events.json` に取り込む。数値の釣り合いは取り込むときに調整するので、Gemini には大まかでよいと伝えてある。

---

## プロンプト

日本を舞台にした政治シミュレーションゲームの「日常の出来事」を考えてください。出力は JSON だけにしてください。

### ゲームの説明

- プレイヤーは一人の新人候補として総選挙での当選を目指し、当選を重ねて役職を上り、首相を目指す。落選しても「浪人」として次の選挙を目指せる。75歳か30年で引退して終わる。
- 1か月に1回、活動（地元回り、街頭演説、政策勉強会、資金集め、党務、県議と連携、地域行事、体力づくり、趣味の時間、休養）を選ぶ。
- 月末に3割ほどの確率で「出来事」が起き、2〜3個の選択肢から1つを選ぶ。選んだ結果で体力や経験点、関係などが増減する。今回考えてほしいのはこの出来事。
- 野球ゲームの育成モードのように、政治以外の日常の出来事（家族、健康、趣味、地元の付き合い、季節の行事、ちょっとした失敗など）も混ぜて、人生を歩んでいる感じを出したい。

### 守ってほしいこと

1. 恋愛の出来事は入れない（配偶者や家族との日常はよい）。
2. 実在の政党、政治家、企業、団体、宗教団体、事件、番組、作品の名前を使わない。ほかのゲームや漫画の名前、キャラクター名も使わない。
3. 地名は都道府県名か、「地元の商店街」「駅前」「県庁所在地」のような一般的な言い方にする。特定の県に結び付けない（どの県の候補でも起きるようにする）。
4. 人物の名前は書かない。「町内会長」「支援者の社長」「県議」「同期の議員」「記者」のように役割で書く。秘書だけは `{secretary}` と書けば秘書の名前に置き換わる。
5. 政党の名前が必要なときは架空の名前を使う：自由民政党（民政党、与党）、立憲民権党（民権党、野党第一党）、日本刷新の会、国民協和党、公正党、れいめい新選組、日本集産党、参画党。ただし、なるべく政党名は出さずに「与党」「野党」「党本部」と書く。
6. 特定の思想、属性、地域、職業の人を笑いものにしない。政治の汚い面（献金、派閥、失言、根回し）は扱ってよいが、違法行為を勧める選択肢を良い結果にしない。
7. 文章は日本語で、短く軽い調子にする。`text`（状況）は60字以内、`result`（結果）は50字以内。

### 出力の形

出来事の配列（JSON）。1つの出来事は次の形。

```json
{
  "id": "rice_planting_help",
  "weight": 2,
  "status": ["候補", "浪人"],
  "months": [5, 6],
  "title": "田植えの手伝い",
  "text": "支援者の農家から「人手が足りない」と電話があった。",
  "choices": [
    {
      "label": "長靴を履いて駆けつける",
      "result": "泥だらけになったが、集落の人たちと打ち解けた。",
      "effects": { "stamina": -12, "relations": { "supporters": 6 }, "jiban_progress": 12 }
    },
    {
      "label": "{secretary}に代わりに行ってもらう",
      "result": "「次は本人が来てね」と言われた。",
      "effects": { "relations": { "secretary": -3, "supporters": 1 } }
    },
    {
      "label": "差し入れだけ届ける",
      "result": "お礼の電話はもらえた。",
      "effects": { "money": -3, "relations": { "supporters": 2 } },
      "risk": {
        "ability": "知名度",
        "threshold": 45,
        "fail_result": "誰からの差し入れか分からず、話題にもならなかった。",
        "fail_effects": {}
      }
    }
  ]
}
```

#### 各項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | 必須 | 英小文字とアンダースコアの一意な名前。下の「すでにある id」と重ねない |
| `weight` | 必須 | 選ばれやすさ。1（まれ）〜4（よくある） |
| `title` | 必須 | 10字以内の題名 |
| `text` | 必須 | 状況の説明（60字以内） |
| `choices` | 必須 | 選択肢を2〜3個 |
| `status` | 任意 | その立場のときだけ起きる。`"候補"`（初当選前）、`"浪人"`（落選中）、`"議員"`（当選中）の配列。書かなければいつでも起きる |
| `post` | 任意 | その役職のときだけ起きる（`status` は `["議員"]` にする）。`"minister"`（大臣・官房長官）、`"pm"`（首相）、`"party_exec"`（党三役）、`"leader"`（野党の党首）の配列 |
| `months` | 任意 | その月だけ起きる（1〜12 の配列）。季節の言葉（祭り、雪、花見、お盆、年末など）が入る出来事には必ず付ける |
| `once` | 任意 | `true` なら一生に一度だけ起きる（健康診断で大きな病気が見つかる、親の引退、など） |

#### 選択肢

| 項目 | 必須 | 内容 |
|---|---|---|
| `label` | 必須 | 選択肢の文（20字以内） |
| `result` | 必須 | 選んだあとの結果（50字以内） |
| `effects` | 必須 | 効果（下の表）。何も起きないなら `{}` |
| `risk` | 任意 | 能力の判定。プレイヤーの能力 `ability` が `threshold` 未満なら、`effects` と `result` の代わりに `fail_effects` と `fail_result` になる。`ability` は `"弁舌"` `"政策"` `"調整"` `"知名度"` `"組織"` `"資金"` のどれか、`threshold` は 40〜75 |

#### 効果（effects）の項目と目安

| 項目 | 意味 | 目安の幅 |
|---|---|---|
| `stamina` | 体力（上限100前後） | -20〜+20 |
| `max_stamina` | 体力の上限 | +2〜+4（まれに -3） |
| `mood` | やる気（1〜5の5段階） | -1 か +1 |
| `money` | 資金（万円）。候補の手元は数百万円 | -100〜+150 |
| `exp` | 経験点。`election`（選挙）、`policy`（政策）、`network`（人脈）、`media`（発信）、`money`（資金）の5種類 | 1つにつき +4〜+20 |
| `relations` | 関係（0〜100）。`secretary`（秘書）、`party`（党の幹部）、`supporters`（後援会）、`press`（地元紙）、`kengi`（県議団） | -10〜+10 |
| `jiban_progress` | 地盤の進み具合（地盤が1段上がるのに70〜200） | +5〜+30 |
| `abilities` | 能力を直接上げ下げする。`弁舌` `政策` `調整` `知名度` `組織` `資金`（1〜100） | ±1〜±3。まれに使う |
| `approval` | 内閣支持率の増減（%）。役職に就いているときの出来事だけに使う | -2〜+1 |
| `skills_add` | 特殊能力を身につける（id の配列。下の表） | 1つ。まれに使う |
| `skills_remove` | 特殊能力が外れる（id の配列） | 1つ。まれに使う |

良い選択肢ばかりにせず、体力やお金を払って関係や経験点を得る、目先は得だが関係が下がる、のような釣り合いのある選択肢にしてください。

### すでにある id（重ねないこと）

すでにある出来事の題名：秋祭りの神輿、秘書の相談、県議の会食、健康診断の結果、大雪、街宣車の故障、ネットで話題に、同期の集まり、母校の講演、農家の手伝い、地元紙の取材、恩師の言葉、委員会での質問、派閥の会合、陳情団、応援演説の依頼、政治資金パーティー、浪人の暮らし、朝の駅頭、国会答弁、所管の不祥事、党内の不穏な動き、首相の決断、代表質問。これらと似た内容も避ける。

### ほしい数と内訳（合わせて60個）

| 種類 | 数 | 例 |
|---|---|---|
| 政治以外の日常（いつでも） | 15 | 家族の行事、親の介護、子どもの受験、ペット、趣味、健康、引っ越し、同窓会、地元のスポーツチーム |
| 季節の行事（`months` 付き） | 12 | 1月から12月まで、どの月にも1つ以上起きるように。花見、入学式、田植え、お盆、花火大会、運動会、紅葉、忘年会、年賀状、成人式など |
| 地元の付き合い（いつでも） | 10 | 商店街、町内会、消防団、PTA、地元企業、災害の後片付け、陳情 |
| 候補と浪人のとき（`status` 付き） | 8 | 公認争い、ポスター貼り、アルバイト、家族の不安、同じ浪人仲間 |
| 議員のとき（`status: ["議員"]`） | 9 | 委員会、議員宿舎、視察、当選同期、党の部会、取材、献金の申し出 |
| 役職のとき（`post` 付き） | 6 | 大臣・首相・党三役・野党の党首それぞれに1〜2個 |

さらに、`once` を付けた一生に一度の出来事を、上の内訳の中に5個ほど含めてください。`risk` のある選択肢は全体の4分の1ほどにしてください。特殊能力を付け外しする出来事は8個ほどにしてください。

出力は、説明文を付けずに JSON の配列だけにしてください（````json` のコードブロックで囲んでよい）。
