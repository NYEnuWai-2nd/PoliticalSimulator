# 議員人生モード CLI版 プレイレポート（2026-11-16）

遊び方：`seiji.mjs` を `--json --seed 7` で起動し、JSONモードでコマンドを送って2つの人生を最後（30年引退）まで通しでプレイした。
方針は共通で、活動は地元回り／街頭演説／県議と連携／党務／地域行事／政策勉強会／資金集めを回し、体力35未満で休養、資金120万円未満で資金集め。経験点は毎月、知名度→弁舌→組織→政策→調整→資金の順に使えるだけ能力上げへ回した。出来事は原則1番の選択肢を選んだ。

## 人生A：新人・立憲民権党・後継・長野県・地方議員型（難しい）

- 松下智章、38歳で立候補。開始時の情勢は自分39.0% 対 民政党候補51.3%。
- 選挙の記録（得票率は自分）：
  - 2028年10月 落選 37.8%（対 鈴木太一 52.0%）
  - 2032年9月 落選 41.7%
  - 2034年10月 落選 47.2%（あと約5ポイント）
  - 2035年10月 落選 42.6%（前年から解散で間隔が約1年しかなく、盛り返せなかった）
  - 2039年11月 **初当選 50.9%**（51歳、浪人生活13年10か月）
  - 2041年3月 当選 55.6%／2045年4月 56.8%／2047年5月 57.0%／2051年6月 57.6%／2055年7月 54.4%
- 2056年1月、68歳・30年で引退。総選挙10回で当選6回。役職は最後までなし（民権党は両プレイ通じて議席16〜24で、政権側にならなかった）。
- 地盤は2033年9月に最大の4、能力は2041年8月に全て100（S）に到達。

## 人生B：名門・自由民政党・小選挙区・徳島県・地方議員型（やさしい）

- 井上智章、33歳。開始時点で資金1,500万円・地盤4・情勢約69%と、Aとは別世界。
- 初選挙（2028年10月）を86.9%で圧勝。以後も71〜85%で勝ち続け、**総選挙9回全勝**。
- 役職の出世：当選3回で防衛大臣（2038年時点）→ 4回で内閣官房長官 → 6回で幹事長。総理大臣には届かず、最後の役職は幹事長。
- 2056年1月、63歳・30年で引退。

## 遊んで気づいたこと（実測に基づく指摘）

1. **中盤以降、経験点が余り続ける**：能力が全て100になった後も経験点が貯まり続け、引退時の未使用分は人生Aで選挙3,144・人脈1,950・発信1,426など。能力カンスト後の使い道（地盤や関係への変換など）があると、後半15年の活動に目的が残ります。
2. **関係（人間関係）が0でも勝ててしまう**：関係は毎月おおむね-2ずつ減り、後半は秘書・党幹部・地元紙などが0のまま推移しましたが、情勢は59〜73%を維持し当選し続けました。関係の効き目が能力・地盤に比べて弱く感じます。
3. **出来事は30年で12種類のみ**：発生107〜113回に対し種類は12種。「秘書の相談」14〜17回、「健康診断の結果」9〜15回など同じ出来事が繰り返し出ます。特に健康診断→「朝のジョギング」は選ぶたびに体力上限が+4ずつ上がり（100→最終130）、繰り返しで上限を伸ばせてしまいます。
4. **地盤の表示あふれ**：地盤4（最大）の後も進捗が貯まり続け、引退時は「1016/-」「1434/-」のような表示になりました。実害はありませんが、カンスト後は表示を止めるか別の表示がよさそうです。
5. **お金は後半ほぼ問題にならない**：維持費は月30万円の一方、資金能力が高いと資金集め1回で+520万円入ります。人生Bは一度も資金に困りませんでした。人生Aでも最低17万円まで減ったのは街宣車の修理（-60万円）が重なった時くらいです。
6. **野党では役職・政権に手が届く気配がない**：2つの人生・60年分を通じ、民政党の議席は常に34〜45で第1党、民権党は16〜24でした。野党プレイでは「政権交代」という目標が立てにくいです。与党プレイ（人生B）でも総理大臣にはなれず幹事長止まりでした（総理は仕様上の上限かもしれません）。
7. **JSONモードの最初の1行**：起動直後に挨拶のJSONが1行出るため、プログラム側は「1コマンド＝1応答」で読むと1行ずつずれます（実際に最初の自動プレイがずれて経験点をほぼ使えませんでした）。人間プレイでは問題ありませんが、AI向けにはREADMEに「起動時の挨拶行を先に読むこと」と一言あると親切です。

## 感想

- 浪人期間の「あと少しで届かない」積み重ね（37.8→41.7→47.2%）は数字が見えるだけに悔しさが実感でき、2039年の初当選50.9%は素直に嬉しかったです。難しい出自の山場としてよくできていると感じました。
- 一方で当選してからは、解散の時期以外に大きな事件がなく、活動の繰り返し感が強くなります。出世（大臣→官房長官→幹事長）は人生Bでちゃんと段階が見えたので、議員になってからの出来事や役職ごとの仕事が増えると、後半の30年がもっと濃くなりそうです。
- 同じseed・同じコマンドで再現できる作りは検証しやすく、今回のように選挙結果を全回分抜き出して比較できました。

検証データ：作業ログ（全コマンドと応答のJSONL）は手元に保存してあります。必要な場合はお渡しできます。
