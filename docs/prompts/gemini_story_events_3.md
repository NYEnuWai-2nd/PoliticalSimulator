# Gemini に頼む：物語の連作（第3弾）――連立の場面、関係の板挟み、首相の物語

使い方：下の「プロンプト」以下をそのまま Gemini に貼る。出力（JSON）は `docs/prompts/output.txt` に貼れば、Claude が中身を確かめて `data/game/stories.json` に取り込む。数値の釣り合いは取り込むときに調整する。第1弾・第2弾のプロンプトは `gemini_story_events.md`、`gemini_story_events_2.md`。

今回の材料は、Muse の「物語と関係の具体案」（`docs/prompts/物語と関係_具体案_2026-11-17.md`）の A（関係の板挟み）と B1（首相の物語）と、0.0.6-alpha で入れた連立の場面（Claude が書いた仮の文）。

---

## プロンプト

日本を舞台にした政治シミュレーションゲーム「議員人生」の、ノベルゲームのような「物語の連作」の第3弾を考えてください。前回まであなたが考えてくれた17本はゲームに入っていて、遊んだ人（自動でプレイする AI の Muse）からも「役職に合った物語が選ばれ、関係の積み上げが育成につながっている」と好評でした。今回はその続きで、次の3つをお願いします。

### ゲームの説明

- プレイヤーは一人の新人候補として総選挙での当選を目指し、当選を重ねて役職を上り、首相を目指す。落選しても「浪人」として次の選挙を目指せる。75歳か30年で引退して終わる。
- 議会は一院制で定数465（過半数233）。小選挙区289区と全国一つの比例区176。政党は架空で、民政党（大きな与党）、民権党（野党第一党）、日本刷新の会、国民協和党、公正党（民政党の連立相手）、れいめい新選組、日本集産党、参画党、保守会議、社平党がある。
- 総選挙のあとに連立を組み直す。第一党が過半数に届かなければ、ほかの党を誘って連立を組む。第一党を中心にしても届かず、第一党を除いた党を束ねれば届くときは、第一党を除いた連合が政権を取ることもある（1993年の非自民連立のような形）。任期の途中で連立相手が抜けることもある。
- プレイヤーが自分の党の党首なら、総選挙のあとに「連立の場面」が出て、連立に加わるか、首相を引き受けるか、第一党を除いた連合を呼びかけるかを選べる。
- 人物との関係（ライバル、同期、党の先輩、秘書）は -100〜100 の数値と、間柄の札（好敵手、因縁、盟友、師弟、恩人、不和）で持つ。同期や先輩の札が盟友・師弟・恩人なら党首選で自分に入れてくれ、不和なら相手に入れる。

### Muse から指摘された問題（今回の狙い）

1. **関係を上げる選択が「正解」になりやすい**：今の物語は、誠実に対応すれば全員との関係が上がるものが中心。2人生を通して遊ぶと関係がほぼ一方的に増え、6種の札のうち「不和」は一度も付かなかった。「誰かを立てれば誰かが離れる」板挟みがほしい。
2. **首相の物語がない**：大臣、与党の役員、野党の党首の物語はあるが、首相の立場でしか起きない物語がない。首相はこのゲームの到達点なので、そこに物語がほしい。
3. **連立の場面の文が薄い**：下に載せる連立の場面4本は、作る側（Claude）が仮に書いた短い文。判断の重さが伝わるように厚くしてほしい。

### 物語の連作の仕組み

- 1本の物語は3〜6の「章」からなる。章は何か月かおきに起き、全画面の場面として出る。
- 場面は会話の形で進む。背景（場所）と話し手の顔の札が出て、セリフが1行ずつ出る。最後に選択肢を2〜3個出す。
- 選択肢を選ぶと、効果（経験点や関係の増減など）が出て、旗（flag）が立ち、次の章が決まる。旗はあとの章の条件や、ほかの物語の条件にも使える。
- 章の条件が、決められた期間のうちに満たされなければ、その物語はそこで終わる（例：ライバルが引退した、落選して議員でなくなった）。終わり方が1つにならないように、結末を2つ以上用意する。
- 選択肢には、選ぶ前に効果を見せない（選んだあとに「関係+15」「政策の経験点+12」のように出す）。そのため、選択肢の文だけで「どういう態度をとるか」が分かるようにする。損得が透けて見える書き方（「得をする」「関係を上げる」など）はしない。

| 書き方 | 人物 | 説明 |

| `secretary` | 秘書 | 最初から付いている。名前は `{secretary}` |
| `rival` | ライバル | 直前の総選挙で自分の区で戦った相手（自分が勝てば次点、負ければ当選者）。相手が出続けるかぎり同じ人。名前は `{rival}`、政党は `{rival_party}`。自分と同じ党のことはない |

#### 物語の項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | 必須 | 英小文字とアンダースコアの一意な名前 |
| `title` | 必須 | 10字以内の題名 |
| `summary` | 必須 | 物語のあらすじ（80字以内。プレイヤーには見せない、取り込む人のための説明） |
| `cast` | 必須 | 出てくる人物（上の表の書き方の配列） |
| `start` | 必須 | 物語が始まる条件（下の「条件」）。`trigger` で始まる時を決める：`"monthly"`（毎月の終わりに条件を見る）、`"after_election"`（総選挙の結果のすぐあと）、`"first_win"`（初当選のすぐあと）、`"post_change"`（役職に就いた・外れたすぐあと）、`"decision"`（自動では始まらず、ゲームが判断の場面として出す。連立の場面だけ） |
| `chapters` | 必須 | 章の配列。最初の章から始まる |
| `endings` | 必須 | 結末の配列（2つ以上） |
| `once` | 任意 | `false` なら一生に何度も起きうる（終わったあと、条件を満たせばまた始まる）。書かなければ一生に一度 |

#### 章の項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | 必須 | 物語の中で一意な名前 |
| `bg` | 必須 | 背景の場所。`office`（地元の事務所）、`campaign`（選挙事務所）、`station`（駅前）、`street`（商店街）、`hall`（公民館・集会所）、`diet`（国会の廊下・委員会室）、`party_hq`（党本部）、`ryotei`（料亭・会食の席）、`home`（自宅）、`hospital`（病院）、`disaster`（被災地）、`tv`（テレビ局・記者会見）のどれか |
| `after_months` | 必須 | 前の章から何か月あとに起きるか（最小と最大）。最初の章は始まる条件を満たしてから |
| `conditions` | 任意 | この章が起きる条件（下の「条件」）。最大の月を過ぎても満たされなければ、`fallback` の結末で終わる |
| `fallback` | 任意 | 条件を満たせなかったときの結末の id。書かなければ何も起きずに終わる |
| `lines` | 必須 | セリフの配列。`speaker` は上の登場人物の書き方、`text` はセリフ。`other` のときは `name` も書く。`face` に表情（`normal` `smile` `angry` `sad` `surprised` `serious`）を書いてよい |
| `choices` | 必須 | 選択肢を2〜3個 |

#### 選択肢の項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `label` | 必須 | 選択肢の文（20字以内） |
| `result` | 必須 | 選んだあとの結果（50字以内） |
| `effects` | 必須 | 効果（下の表）。何も起きないなら `{}` |
| `flags` | 任意 | 立てる旗（英小文字の配列） |
| `next` | 必須 | 次の章の id か、結末の id |
| `if_flags` | 任意 | この旗がすべて立っているときだけ出る選択肢 |
| `risk` | 任意 | 能力の判定。プレイヤーの能力 `ability`（`"弁舌"` `"政策"` `"調整"` `"知名度"` `"組織"` `"資金"`）が `threshold`（40〜75）未満なら、`fail_result`、`fail_effects`、`fail_next` になる |

#### 条件（start と conditions に書ける項目）

| 項目 | 内容 |
|---|---|
| `status` | `"候補"`（初当選前）、`"浪人"`（落選中）、`"議員"`（当選中）の配列 |
| `post` | `"minister"`（大臣・官房長官）、`"pm"`（首相）、`"party_exec"`（党三役）、`"leader"`（野党の党首）、`"opp_exec"`（野党の役職）、`"none"`（役職なし）の配列 |
| `ruling` | `true` なら自分の党が与党のとき、`false` なら野党のとき |
| `terms_min` / `terms_max` | 当選回数 |
| `age_min` / `age_max` | 年齢（始めは30〜50歳ほど） |
| `abilities` | 能力の下限。例：`{ "弁舌": 60 }` |
| `relations` | 集団との関係の下限。`secretary` `party` `supporters` `press` `kengi`（0〜100）。例：`{ "party": 60 }` |
| `bonds_min` / `bonds_max` | 人物との関係の下限と上限（-100〜100）。例：`{ "rival": 30 }` |
| `bond_state` | 人物の関係の札。例：`{ "rival": "因縁" }` |
| `jiban_min` | 地盤の下限（1〜4） |
| `skills` / `no_skills` | その特殊能力を持っている／持っていない（下の id の配列） |
| `flags` / `no_flags` | その旗が立っている／立っていない |
| `months` | その月だけ（1〜12 の配列） |
| `won_last` | `true` なら直前の総選挙で勝った、`false` なら負けた |
| `margin_max` | 直前の総選挙の自分とライバルの得票率の差（ポイント）がこれ以下 |

#### 効果（effects）の項目と目安

| 項目 | 意味 | 目安の幅 |
|---|---|---|
| `stamina` | 体力（上限100前後） | -20〜+20 |
| `mood` | やる気（1〜5の5段階） | -1 か +1 |
| `money` | 資金（万円） | -100〜+150 |
| `exp` | 経験点。`election`（選挙）、`policy`（政策）、`network`（人脈）、`media`（発信）、`money`（資金） | 1つにつき +4〜+25 |
| `relations` | 集団との関係 `secretary` `party` `supporters` `press` `kengi` | -10〜+10 |
| `bonds` | 人物との関係 `rival` `doki` `senpai` `secretary`。1つの選択肢で、ある人とは上がり別の人とは下がる、のように逆向きに動かしてよい（例：`{ "doki": 15, "senpai": -10 }`） | -25〜+25 |
| `bond_state` | 人物の関係の札を付ける。`好敵手` `因縁` `盟友` `師弟` `恩人` `不和` のどれか | 結末で使う |
| `jiban_progress` | 地盤の進み具合（1段上がるのに70〜200） | +5〜+40 |
| `abilities` | 能力の増減 `弁舌` `政策` `調整` `知名度` `組織` `資金`（1〜100） | ±1〜±4 |
| `approval` | 内閣支持率の増減（%）。役職に就いているときだけ | -3〜+2 |
| `vote_bonus` | 次の総選挙の自分の区の得票に足すポイント | -3〜+3 |
| `coalition` | 連立の場面の判断（下の「連立の場面」の物語だけで使う）。`join` 加わる、`outside` 閣外協力、`decline` 断る、`pm_accept` 首相を引き受ける、`pm_yield` 譲る、`call` 連合を呼びかける | 1つ |

#### 特殊能力の id

金（強力）：`senkyo_kamisama`（選挙の神様）、`nemawashi_oni`（根回しの鬼）、`ronpa_ou`（論破王）。青（利点）：`dobuita`（ドブ板）、`tsuji_seppou`（辻説法）、`tairyoku_jiman`（体力自慢）、`hasshinryoku`（発信力）、`kengi_pipe`（県議とのパイプ）、`zaikai`（財界人脈）、`dandori`（段取り上手）、`genba_no_koe`（現場の声）。赤（欠点）：`shitsugen`（失言癖）、`enjou`（炎上体質）、`jimoto_fuzai`（地元不在）、`chousei_heta`（調整下手）、`kurou_shirazu`（苦労知らず）、`byoujaku`（病弱）。緑（両面）：`ippiki_ookami`（一匹狼）、`gekijougata`（劇場型）。

#### 2. 関係の板挟みの物語を6本

- **同期と先輩のどちらに付くか**（2本）：党内の対立や人事で、同期と先輩が別の側に立つ。どちらかに付けば、もう一方との関係が下がる（例：同期 +15／先輩 −10 と、その逆）。中立を選ぶと、両方から少しずつ信頼を失う選択肢もあってよい。
- **党首選の前の根回し**（2本）：党首選に立候補する数か月前に「誰に頭を下げるか」を選ぶ。選んだ相手との関係が上がり、選ばなかった相手は不満を持つ。結末で、選んだ相手に盟友・師弟・恩人の札、こじれた相手に不和の札が付くようにする。条件に `terms_min`（当選3回以上など）を使う。
- **「不和」になった相手との修復か決裂**（2本）：`bond_state` が不和のライバル、同期、先輩のどれかを条件に始まる。修復を選べば札が消える方向（関係が上がり、結末で盟友や好敵手になる）、決裂を選べば因縁になる。修復は難しく（`risk` を付ける）、決裂にも得るものがある（経験点や後援会の支持など）。

#### 3. 首相の物語を4本

`post: ["pm"]` を条件にする。題材の例：

- 官邸での秘書との関係（忙しさと信頼、秘書の健康、秘書を官邸に連れていくか）
- 与党の党首としての同期との距離（同期を重要閣僚に起用するか、えこひいきと言われるか）
- 連立相手の党首との交渉（連立の維持と政策の譲歩）
- 歴史に残る決断（支持率を下げても進める改革か、目先の人気か）

それぞれ3〜5章、結末は2〜3個。選択肢のうち4分の1ほどに `risk` を付ける。首相の物語では `approval`（内閣支持率）の増減を使ってよい（-3〜+2）。

### 守ってほしいこと

1. 恋愛は入れない（配偶者や家族との日常はよい）。
2. 実在の政党、政治家、企業、団体、宗教団体、事件、番組、作品の名前を使わない。ほかのゲーム、漫画、ドラマの名前やキャラクター名、筋書きを写さない。1993年の非自民連立のような現実の出来事は、型として参考にするだけにして、実在の人物や政党を思わせる書き方をしない。
3. 地名は `{pref}` `{district}` か、一般的な言い方にする。
4. どの政党、政治的立場にも肩入れしない。相手を悪役に決めつけず、言い分と魅力を持たせる。
5. 特定の思想、属性、地域、職業の人を笑いものにしない。違法行為を勧める選択肢を良い結果にしない。
6. 文章は日本語。セリフは1行60字以内、1章のセリフは4〜10行。選択肢の文は20字以内、結果の文は50字以内。
7. 1つのセリフの中で「です・ます」と「だ・である」を混ぜない。話し手ごとに口調をそろえる（秘書はプレイヤーを「先生」と呼び、です・ます調。同期は友達の口調）。
8. ゲームの中の言葉に合わせる：「党の幹部」（「執行部」は使わない）、「内閣支持率」、「政策勉強会」、「持ち味」（特殊能力のこと）、「首相」（会話の呼びかけでは「総理」でよい）。
9. ふつう使われない造語を作らない。比喩より、直接的で説明的な言葉を使う。古風な文語（「告ぐ」「知りて」など）や大げさな比喩（「十字架を背負う」など）を使わない。
10. 選択肢の文だけで、どういう態度をとるかが分かるようにする（選ぶ前に効果は見せないので、損得が透けて見える書き方をしない）。
