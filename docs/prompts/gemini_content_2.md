# Gemini に頼む：法案、政局の出来事、活動の結果の文

使い方：下のプロンプト A、B、C は別々の会話（または別々のメッセージ）で Gemini に貼る。1回にまとめると出力が長すぎて途中で切れやすいため。出力（JSON）はそれぞれ `docs/prompts/output.txt` に貼るか、このチャットに添付すれば、Claude が中身を確かめて取り込む。数値は取り込むときに調整する。

3つとも、最初に下の「共通の説明」を付けて貼る（A なら「共通の説明」＋「プロンプト A」）。

---

## 共通の説明

日本を舞台にした政治シミュレーションゲームの文章とデータを作ってください。出力は JSON だけにしてください。

### ゲームの説明

- プレイヤーは一人の政治家として、新人候補から当選を重ね、役職を上り、首相を目指す。国会は一院制で定数76（小選挙区47、比例29）、過半数は39。
- 与党は固定されていない。総選挙のあとに連立を組み直し、政権交代が起きる。首相は与党の党首。
- 首相は法案を準備して国会に出し、採決で過半数を取ると成立する。議員は党の方針に従って投票するが、自分の思想と法案が離れていると造反することがある。
- 毎月の終わりに、政局の出来事（閣僚の失言、景気の変化、災害など）が起き、内閣支持率が動く。

### 守ってほしいこと

1. 実在の政党、政治家、企業、団体、宗教団体、事件、番組、作品、法律の正式名を使わない。ほかのゲームや漫画の名前も使わない。
2. 地名は都道府県名か一般的な言い方（「地元の商店街」「被災地」「県庁所在地」）にする。特定の県に結び付けない。
3. 人物の名前は書かない。役割で書く。
4. 政党の名前が必要なときは架空の名前を使う：自由民政党（民政党。保守、長く与党）、立憲民権党（民権党。中道左派、野党第一党）、日本刷新の会（刷新。改革・地方分権）、国民協和党（協和党。中道、積極財政）、公正党（中道、福祉、民政党と連立）、れいめい新選組（れいめい。左派、積極財政）、日本集産党（集産党。左派）、参画党（右派、新興）。なるべく党名は出さず「与党」「野党」「連立相手」と書く。
5. 特定の思想、属性、地域、職業の人を笑いものにしない。どの政治的立場にも肩入れせず、賛成と反対の両方に理由があるように書く。
6. 恋愛の話は入れない。
7. 日本語で書く。

### 思想の5つの軸

法案や議員の思想は5つの軸（−3〜+3）で表す。

| id | 軸 | −（マイナス）の側 | ＋（プラス）の側 |
|---|---|---|---|
| `economy` | 経済 | 市場重視 | 再分配重視 |
| `fiscal` | 財政 | 積極財政 | 財政規律 |
| `security` | 安保 | 抑止重視 | 対話重視 |
| `social` | 社会 | 伝統重視 | 多様性重視 |
| `governance` | 統治 | 改革・分権 | 安定 |

各党のおおよその位置：民政党は 安保−2・社会−1.5・統治+2、民権党は 経済+1.5・安保+1・社会+2、刷新は 経済−1.5・統治−2.5、協和党は 財政−2、公正党は 経済+1・安保+1、集産党は 経済+2.5・安保+2.5・社会+2。

## プロンプト A：法案（16件）

政府が国会に出す法案を16件考えてください。

### 出力の形

```json
[
  {
    "id": "child",
    "name": "子育て支援拡充法案",
    "field": "厚生・労働",
    "ideology": { "economy": 1.5, "social": 1 },
    "work": 4,
    "on_pass": 3,
    "description": "再分配寄り。野党の多くが賛成しやすいが、財政規律派は渋る。"
  }
]
```

| 項目 | 内容 |
|---|---|
| `id` | 英小文字とアンダースコアの一意な名前 |
| `name` | 法案の名前（「〜法案」「〜改正案」）。実在の法律の正式名と同じにしない |
| `field` | 担当する分野。`財政・税制` `経済・産業` `農林水産` `厚生・労働` `教育` `国土・交通` `外交` `安全保障` `法務・治安` `地方・行政` のどれか |
| `ideology` | 法案の思想の位置。関係する軸だけを書く（1〜2軸）。−3〜+3、0.5刻み |
| `work` | 準備に必要な量。2（簡単）〜6（大がかり） |
| `on_pass` | 成立したときの内閣支持率の変化。−3〜+4。世論に人気の法案はプラス、必要だが不人気な法案はマイナス |
| `description` | どの党や議員が賛成・反対しやすいかの説明（60字以内）。上の例のように、連立相手の中からも反対が出る、などの力学を書く |

### 内訳

- 10の分野のどれにも1件以上。
- 思想の向きが偏らないように。5つの軸のそれぞれで、−の側と＋の側の両方の法案を入れる。
- 世論に人気だが財政に厳しい法案、必要だが不人気な法案（増税、社会保障の見直しなど）、与党内が割れる法案、野党も賛成しやすい法案を混ぜる。
- すでにある法案と重ねない：予算、子育て支援拡充、所得税減税、防衛力強化、地方創生交付金、選択的夫婦別姓、政治資金規正法改正、原発再稼働推進、農業所得補償。

出力は説明文を付けずに JSON の配列だけにしてください。

## プロンプト B：政局の出来事（20件）

毎月の終わりに起きうる政局の出来事を20件考えてください。起きると内閣支持率が動き、ポップアップで短い会話の場面が出る。

### 出力の形

```json
[
  {
    "id": "gaffe",
    "weight": 3,
    "target": "cabinet_low_speech",
    "approval": -3,
    "title": "閣僚の失言",
    "text": "{member}が記者会見で失言し、批判を浴びた。",
    "lines": [
      { "speaker": "reporter", "text": "先ほどの発言は、被災された方々への配慮に欠けるのではありませんか。" },
      { "speaker": "member", "text": "え、いや、その……そういう意味で申し上げたのではなく……。" },
      { "speaker": "chief_cabinet_secretary", "text": "総理、すぐに釈明させます。これ以上、騒ぎが大きくならないように。" },
      { "speaker": "pm", "text": "言葉一つで政権が揺らぐ。肝に銘じてもらわないと困る。" }
    ]
  }
]
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | 必須 | 英小文字とアンダースコアの一意な名前 |
| `weight` | 必須 | 選ばれやすさ。1（まれ）〜3（よくある） |
| `target` | 任意 | 当事者の選び方。`"cabinet_low_speech"`（弁舌の低い閣僚ほど選ばれる。失言など）、`"ruling_member"`（与党の議員から選ぶ。疑惑など）。当事者がいない出来事では書かない |
| `approval` | 必須 | 内閣支持率の変化（%）。−5〜+3 |
| `cohesion` | 任意 | 与党の結束の変化。−0.1〜+0.05（党内の対立や造反の芽になる出来事に使う） |
| `months` | 任意 | その月だけ起きる（1〜12の配列）。台風、猛暑、年末の予算編成など季節のある出来事に付ける |
| `title` | 必須 | 12字以内の題名 |
| `text` | 必須 | 記録に残る1文（50字以内）。当事者は `{member}` と書くと名前に置き換わる |
| `lines` | 必須 | 場面の会話を3〜4行。1行40字以内 |

`speaker` に使える役割：`pm`（首相）、`chief_cabinet_secretary`（官房長官）、`secretary_general`（与党の幹事長）、`opposition_leader`（野党第一党の党首）、`member`（当事者。`target` があるときだけ）、`reporter`（記者）、`chair`（議長）、`narrator`（地の文。話し手の名前を出さない）。

### 内訳

- 支持率が上がる出来事を6件ほど、下がる出来事を10件ほど、どちらとも言えない（小さく動く）出来事を4件ほど。
- 種類を散らす：外交（首脳会談、領海の緊張、国際会議）、経済（株価、円安・円高、賃上げ、倒産）、災害と季節（台風、猛暑、大雪、感染症）、政治とカネ、党内の対立や造反の動き、世論調査、内閣改造の噂、野党の追及、閣僚の辞任、明るい話題（スポーツ選手の活躍、皇室以外の国民的な祝い事など）。
- 会話は、首相や官房長官が落ち着いて受け止める、野党が追及する、記者が質問する、のように本物の政治の場面らしく抑えた調子にする。茶化しすぎない。
- すでにある出来事と重ねない：閣僚の失言、政治資金の疑惑、景気指標が好調、物価高への不満、大雨への対応、首脳会談。

出力は説明文を付けずに JSON の配列だけにしてください。

## プロンプト C：活動の結果の短い文（100行）

プレイヤーが毎月選ぶ活動のあとに、結果の数値と一緒に出す短い文（情景の一言）を作ってください。毎月同じ文にならないよう、季節や立場で変わる文をたくさん用意したい。

### 活動の種類

| id | 活動 | 内容 |
|---|---|---|
| `local` | 地元回り | 支援者の家や商店、集落を一軒ずつ回る |
| `speech` | 街頭演説 | 駅前や交差点で演説する |
| `study` | 政策勉強会 | 専門家や官僚を招いて政策を学ぶ |
| `fund` | 資金集め | 支援者や企業を回って献金を頼む、資金パーティーを開く |
| `party` | 党務 | 党本部や県連の仕事を手伝う |
| `kengi` | 県議と連携 | 県議会議員と会合を持ち、協力を頼む |
| `festival` | 地域行事 | 祭り、運動会、清掃などの地域の行事に出る |
| `training` | 体力づくり | ジョギング、ジム、散歩 |
| `hobby` | 趣味の時間 | 趣味で気分転換する |
| `rest` | 休養 | 休む |

### 出力の形

```json
{
  "local": [
    { "text": "田んぼのあぜ道で、草取りの手を止めて話を聞いてくれた。", "months": [6, 7] },
    { "text": "「また来たの」と笑われたが、お茶を出してくれた。", "jiban": "high" },
    { "text": "インターホン越しに名乗っても、なかなか出てきてもらえない。", "jiban": "low" },
    { "text": "「当選したら忘れないでよ」と念を押された。", "status": ["候補", "浪人"] },
    { "text": "{secretary}が作った訪問名簿の半分を回り終えた。" }
  ],
  "speech": [ ... ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `text` | 必須 | 1文、35字以内。数値の結果（経験点が増えた、など）は書かない。情景や人の反応を書く。秘書は `{secretary}` と書くと名前に置き換わる |
| `months` | 任意 | その月だけ出る（季節の言葉が入るときは必ず付ける） |
| `status` | 任意 | その立場のときだけ出る。`"候補"`（初当選前）、`"浪人"`（落選中）、`"議員"`（当選中） |
| `jiban` | 任意 | 地盤の固さ。`"low"`（まだ顔を知られていない）か `"high"`（地元でよく知られている）のときだけ出る |

### 内訳

- 10の活動それぞれに10文、合わせて100文。
- 各活動の10文のうち、条件なしを4文ほど、`months` 付きを3文ほど（春夏秋冬に散らす）、`status` か `jiban` 付きを3文ほど。
- 議員になってからの文は、国会の会期、議員宿舎、委員会、東京と地元の往復など、議員らしい場面にする。
- 明るい文ばかりにせず、空振り、雨、疲れ、冷たい反応などの小さな苦労も混ぜる。

出力は説明文を付けずに JSON のオブジェクトだけにしてください。
