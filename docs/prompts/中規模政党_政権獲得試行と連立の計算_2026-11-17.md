# 中規模政党は政権を取れるか（試行結果と連立の計算）

- 対象版：v0.0.3-alpha（f1b6aae、465議席制）
- 構成：第1部＝中規模3党の政権獲得試行の結果、第2部＝刷新・協和が連立に誘われない理由を連立形成の計算から特定したもの
- 実施：2026-11-17

# 第1部　中規模政党の政権獲得試行

- 依頼：民政・民権以外で、まず中規模政党が政権を取れるか試す
- 方法：固定方針の自動プレイ（前回の全政党試行と同じ方針）で30年フルキャリアを各党60試行。開始条件は各党の一番強い地盤を自動選択（刷新＝世襲・小選挙区、協和＝世襲・小選挙区、公正＝比例・東京ほか prefs 準拠）
- 記録した段階：①自党が政権与党に入る ②自党が政権の主導党になる ③本人が首相になる
- 実行：合計180試行・クラッシュ0件、1試行あたり約5秒

## 結果

| 党（開始議席） | 政権入り | 政権の主導 | 本人が首相 | 自党の最大議席（最高／中央値） | 引退時の役職（最多） |
|---|---|---|---|---|---|
| 刷新党（38） | **0 / 60** | 0 / 60 | 0 / 60 | 48 ／ 34 | 党の幹事長 53 |
| 協和党（28） | **0 / 60** | 0 / 60 | 0 / 60 | 45 ／ 32 | 党首 58 |

## 読み取れること

- **刷新党と協和党は、政権に一度も入れませんでした。** 連立に誘われること自体がないのが現状です。標準2人生（seed 7）の政権の顔ぶれとも一致します：顔を出すパートナーは公正党・集産党・社平党・保守会議・参画党で、刷新・協和は両人生とも一度も与党に入りませんでした
- 協和党は本人が党首になれる（58/60）のに政権に入れない、という一番くっきりした壁です。議席も中央値で28→32と微増し、最高45まで伸びるのに、連立の声がかかりません
- 公正党は逆に、開始時点から与党（民政党との連立）で60試行全て政権内ですが、主導権は一度も来ず、本人の到達点は国土交通大臣（34/60）。旧76議席制と同じ「永遠の下位パートナー」です
- 議席の天井も低く、刷新の最高48・協和の最高45は、第一党（150〜230）には遠く及びません。主導以前に「誘われない」段階で止まっているのが今回の核心です

# 第2部　刷新・協和が連立に誘われない理由（連立形成の計算から）

- 対象：`src/game/politics.ts` の `formCoalition` と `data/game/politics.json` の定数、`data/game/parties.json` の思想中心
- 前提の観測：第1部の試行で刷新・協和は政権入り0/60、標準2人生でも両党は一度も与党に入らなかった

## 連立の組み方（3段階）

1. **現政権の継続が最優先**：前回の与党ブロックが過半数（233）を保てば、そのまま続投。組み替え自体が起きない
2. **新しい連立**：第一党が、思想の距離（5軸の差の絶対値の平均）が **2.0以内** の党を近い順に、過半数に届くまで **最大2党** だけ誘う
3. **少数与党の判定**：新しい連立が過半数に届かない場合、前回の与党ブロックと議席数を比べ、多いほうが政権を担う（=新連立は「前政権より大きくないと」政権交代できない）

## 距離の順位表（近い順、太字は実際に選ばれる範囲）

民政党から：**保守会議 1.1 → 参画党 1.5** → 公正党 1.6 → 協和党 1.8 → 刷新 1.9 → 民権党 2.3（圏外）

民権党から：**集産党 0.7 → 社平党 0.8** → 公正党 0.9 → れいめい 1.2 → 協和党 1.5 → 刷新 2.4（**距離の上限2.0を超えて圏外**）

## 刷新・協和が外れる理由（3つの仕組みの重なり）

- **協和党は「順番が回ってこない」**：民政党からは4番目、民権党からは5番目。パートナーは最大2党で、しかも過半数に届いた時点で打ち止めになるため、順番が来る前に連立が閉じてしまう。民政党が230議席を取った選挙では保守会議（3議席）を加えて233に届き、1党で打ち止めになった実例もある
- **刷新は「距離の上限で門前払い」**：民権党との距離2.4が上限2.0を超え、民権党主導の連立には原理的に入れない。民政党からは圏内（1.9）だが最後尾。統治軸が −3（改革派）と極端で、どの党からも遠いのが効いている
- **現政権の継続ルールが公正党を固定する**：公正党は新しい連立の順位では民政党から3番目で、本来は選ばれない。しかし開始時の与党（民政＋公正＝215）が「前回のブロック」として残り、段階1・3の継続判定で勝ち続けるため、公正党だけが入り続ける。逆に言えば、刷新・協和はこの継続の輪にも入っていない

## 検証（計算の予測と実際の政権が一致）

| 場面 | 計算どおりの予測 | 実際の観測 |
|---|---|---|
| 開始直後の選挙（民政175） | 新連立は民政+保守+参画=182 ＜ 現ブロック198 → 現政権が少数与党で継続 | 「民政党・公正党が少数与党として政権を続ける（198議席）」 |
| 人生B 2035年（民権167） | 民権+集産+社平=182 ＞ 現ブロック180 → 政権交代 | 「民権党・集産党・社平党が少数与党として政権を担う（182議席）」 |
| 人生B 2040年（民政230） | 保守会議を加えて233に到達、1党で打ち止め | 「民政党・保守会議が政権を担う」 |

## 緩和するなら（論点の提示）

- パートナー上限（2党）を増やす：ただし民権党側では協和は5番目で、上限3でも公正党止まり。効きは限定的
- 距離の上限（2.0）を上げる：刷新が民権党連立の圏内に入る（2.4）。ただし近い順の原則では最後尾のまま
- 継続ルール（段階3）の比較条件を緩める：政権交代の頻度そのものが上がる
- 根本的には「近い順に過半数まで」という選び方が、両端の小政党を最安の買い物にしている。中規模政党に声がかかるには、大臣ポストの配分や政策の一致など、議席以外の価値が連立の計算に入る必要がある
