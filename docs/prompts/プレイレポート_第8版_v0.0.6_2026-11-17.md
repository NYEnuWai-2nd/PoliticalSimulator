### 読み取れること

- **集産党が連合の「中心」として常態化しています。** 方針1では主導29/30・首相29/30。開始時8議席の党が、議席の重み付き距離が最小という理由で連合の首相党に選ばれ続けます。集産党を中心とする連合の検出は方針1で37件あり、集産党が主導した人生は29/30でした。「小さい党の首相」は1993年型の醍醐味ですが、ここまで固定的だと、集産党の人生だけ難易度が大きく下がります
- **公正党に初めて首相の道が開きました**（方針1で9/30）。場面の「首相の座」と連合の中心選びの両方が効いています
- **刷新・協和党の壁は「主導」へ移ったまま**です。政権入りは安定しましたが、主導・首相は方針2でも刷新3/30・協和党5/30にとどまります
- **れいめいだけ党首に一度もなれていません**（両方針とも0/30、60人生すべて幹事長止まり58/60・大臣2）。党の最大議席も18〜19議席。他党では党首到達が普通に起きるため、れいめいの党首選だけ到達可能性を確認する価値があります
- 場面の発生は合計で方針1が377回・方針2が341回。民権党・集産党・公正党の人生に集中します

## 試行B：政局の動きの量（試行Aの600人生から集計）

- 政権交代（与党第一党の交代）：方針1で平均2.69回／30年、方針2で2.86回／30年。10年に1回程度で、過剰ではありません
- 少数与党に終わる総選挙：方針1で27.5%、方針2で30.0%（全2,382回／2,379回の総選挙中）
- 第一党の議席：最大337〜363、最小でも160〜164。第一党の壊滅的な敗北や消滅は起きていません
- 第一党を除いた連合の検出：方針1で185件、方針2で160件（選挙の約7〜8%）。主導は民権党が最多（132／92件）、次いで集産党（37／19件）、公正党（9／15件）。民政党が主導して民権党を除く形も少数あります（方針2で13件）
- 任期途中の与党構成の変化：別途60人生で測定し、平均1.6回／人生（49/60人生で1回以上）。v0.0.5 の標準2人生で見た頻度（2人生で3回）と同程度です。なお政局ログの文面（「〜が連立を離脱した」）は CLI の応答には含まれないため、内訳（離脱か組み直しか場面による交代か）の切り分けは CLI からはできませんでした

## 試行C：連立の場面の手触り

協和党の人生（シード13478、世襲・小選挙区）で選択肢を意図的に変えて検証しました。

- 「連立への誘い」で **1（加わる）** → 民政党・協和党・公正党の連立入りし、国土交通大臣に就任。提示どおりの結果です
- **2（閣外から協力する）** → 連立には入らず（与党は民権党・公正党・集産党のまま）、役職は協和党の党首のまま。閣外協力として扱われています
- **3（断る）** → 自党を除いて組み直され、与党は民政党・公正党・参画党に（協和党の代わりに参画党が入る）。提示どおりの結果です
- その後の誘いを「加わる」にすると法務大臣・国土交通大臣に就任。連立相手へのポスト配分は議席比に応じて変わります
- 文面は具体的で分かりやすいです。秘書の平野が「民権党・公正党・協和党・刷新で組めば、政権を取れるかもしれません」と組める顔ぶれまで示すため、何が起きるかを読んで選べます。選択肢には判定のヒント（［人脈・関係・政権・判定：調整］）も付いています
- 標準人生Aでは「連合の呼びかけ」が3回とも成功し、6党連合を含む政権交代が起きました。呼びかけの成否は調整の判定で、ベテラン党首（調整S）では成功が続きました。駆け出しの党首での成功率は未検証です
- 気になる点：呼びかけ（通常）と呼びかけ（強硬）の文面は同一で、違いは判定の難しさだけです。与党が過半数を持っている場合でも語り手の文は「過半数に届かないか、届いてもわずかな差になった」のままで、状況と文面がずれる場面があります

## 試行D：互換性・表記・停止

- 旧セーブ：形式3の実データ（能力「資金」を含む）を読み込み、「資金力」へ直したうえで、総選挙を挟む40か月を無変更の人生と同一の軌跡で進行できることをテストで確認。形式2相当（物語・間柄の項目なし）も読み込めて6か月進行しました
- 都道府県の表記：北海道＝道議、京都・大阪＝府議、東京＝都議、徳島＝県議と、開始地に合った呼び方だけが表示されることを CLI で確認しました
- **停止する不具合を1件、再現手順つきで確認しました（重要）**
  - 内容：組閣の処理（formGovernment）が「〜に就ける議員がいません」というエラーを投げて、CLI のプロセスがそのまま終了します。役職名は総務会長・経済産業大臣など回によって変わります
  - 再現手順（de417f5）：シード10222、`start newcomer shusan pr 13 local`、固定方針（行動は巡回、場面は常に1番）で327か月目、総選挙後の場面「連合の呼びかけ」で「各党に連合を呼びかける」を選ぶと停止します（2回再現）
  - 060e4c8 ビルドでは同じ人生が302か月目に、場面ではなく通常の総選挙後の組閣で停止しました。つまり場面固有ではなく、「小さい党が政権を率いるときに、党三役や大臣に就ける議員が足りなくなる」ことが根で、総選挙のたびに起こりえます
  - 頻度：試行Aの600人生中47人生（7.8%）がこのエラーで終了しました。内訳は社平党の人生23、保守会議17、集産党5、協和党1、参画党1と、小さい党の人生に集中しています

## 改善提案

1. **組閣で議員が足りない場合にエラーを投げないこと**（最優先）。就任できる議員がいない役職は空席にするか、資格の条件（当選回数など）をその党の議員数に応じて緩めるか、どちらかで落下を止めてください。小さい党の連合政権は今回の目玉の仕組みなので、そこで止まるのは惜しいです
2. **集産党の中心への偏り**。重み付き距離が最小の党が首相党になる計算では、集産党（イデオロギー座標のほぼ中央）がほぼ常勝します。中心の判定に議席の下限（例：連合内での議席割合）を入れる、または2番手以降の党にも中心が回る余地を検討してください
3. **れいめいの党首選の到達可能性**。60人生で党首0回・幹事長止まり58回は、他党と比べて際立っています。現党首の強さか、比例単独開始の到達条件か、一度確認をおすすめします
4. 呼びかけ（強硬）の文面。与党が過半数のときは語り手の文を状況に合わせると、難しさの違いも伝わります
5. 政局ログ（離脱・組み直し）を CLI の応答にも出すと、自動検証で内訳まで追えます
