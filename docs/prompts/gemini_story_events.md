# Gemini に頼む：物語の連作とライバルの人物像

使い方：下の「プロンプト」以下をそのまま Gemini に貼る。出力（JSON）は `docs/prompts/output.txt` に貼れば、Claude が中身を確かめて `data/game/stories.json` などに取り込む。数値の釣り合いは取り込むときに調整する。設計は `docs/design.md` の5.6節。

---

## プロンプト

日本を舞台にした政治シミュレーションゲーム「議員人生」の、ノベルゲームのような「物語の連作」と「ライバルの人物像」を考えてください。

### ゲームの説明

- プレイヤーは一人の新人候補として総選挙での当選を目指し、当選を重ねて役職を上り、首相を目指す。落選しても「浪人」として次の選挙を目指せる。75歳か30年で引退して終わる。
- 1か月に1回、活動（地元回り、街頭演説、政策勉強会、資金集め、党務、県議と連携、地域行事、体力づくり、趣味の時間、休養）を選ぶ。月末に3割ほどの確率で、1画面で終わる日常の出来事が起きる。
- 議会は一院制。小選挙区は都道府県ごとに区があり（東京は1区〜30区、鳥取は1区と2区など、全国で289区）、ほかに全国一つの比例区がある。プレイヤーはどこか1つの区から出る。
- 野球ゲームの育成モードのように、能力のランク、特殊能力、地盤（選挙区での固い支持）でキャラクターを表す。
- 今の出来事は単発で、前後がつながらない。人物との関係もない。そこで、何か月かおきに続く物語と、特定の人物との関係を足したい。今回考えてほしいのはその中身。

### 物語の連作の仕組み

- 1本の物語は3〜6の「章」からなる。章は何か月かおきに起き、全画面の場面として出る。
- 場面は会話の形で進む。背景（場所）と話し手の顔の札が出て、セリフが1行ずつ出る。最後に選択肢を2〜3個出す。
- 選択肢を選ぶと、効果（経験点や関係の増減など）が出て、旗（flag）が立ち、次の章が決まる。旗はあとの章の条件や、ほかの物語の条件にも使える。
- 章の条件が、決められた期間のうちに満たされなければ、その物語はそこで終わる（例：ライバルが引退した、落選して議員でなくなった）。終わり方が1つにならないように、結末を2つ以上用意する。

### 登場人物（物語に出せる人）

| 書き方 | 人物 | 説明 |
|---|---|---|
| `self` | プレイヤー | セリフの話し手にできる。名前は `{self}` |
| `secretary` | 秘書 | 最初から付いている。名前は `{secretary}` |
| `rival` | ライバル | 直前の総選挙で自分の区で戦った相手（自分が勝てば次点、負ければ当選者）。相手が出続けるかぎり同じ人。名前は `{rival}`、政党は `{rival_party}`。自分と同じ党のことはない |
| `doki` | 同期 | 自分の初当選と同じ選挙で初当選した、同じ党の議員。名前は `{doki}` |
| `senpai` | 党の先輩 | 初当選のときに付く、同じ党の当選回数の多い議員。名前は `{senpai}` |
| `narrator` | 地の文 | 状況の説明 |
| `other` | そのほかの人 | 役割の名前を `name` に書く（例：`"name": "町内会長"`）。人の名前は書かない |

そのほかに使える置き換え：`{district}`（例：東京7区）、`{pref}`（県名）、`{party}`（自分の党）。

### 守ってほしいこと

1. 恋愛は入れない（配偶者や家族との日常はよい）。
2. 実在の政党、政治家、企業、団体、宗教団体、事件、番組、作品の名前を使わない。ほかのゲーム、漫画、ドラマの名前やキャラクター名、筋書きを写さない。
3. 地名は `{pref}` `{district}` か、「地元の商店街」「駅前」のような一般的な言い方にする。どの県の候補でも起きるようにする。
4. どの政党、政治的立場にも肩入れしない。ライバルを悪役に決めつけず、ライバルにも言い分と魅力を持たせる。
5. 特定の思想、属性、地域、職業の人を笑いものにしない。政治の汚い面（献金、派閥、失言、裏切り、スキャンダル）は扱ってよいが、違法行為を勧める選択肢を良い結果にしない。
6. 文章は日本語。セリフは1行60字以内、1章のセリフは4〜10行。選択肢の文は20字以内、結果の文は50字以内。

### 出力の形

JSON のオブジェクトを1つ。`stories`（物語の配列）、`rival_types`（ライバルの人物像の配列）、`bond_states`（関係の札の効果の案）の3つを持つ。

```json
{
  "stories": [
    {
      "id": "rival_rematch",
      "title": "宿命の再戦",
      "summary": "初めての選挙で競り合った相手と、同じ区で戦い続ける話。",
      "cast": ["rival", "secretary"],
      "start": { "trigger": "after_election", "status": ["議員", "浪人"], "rival_in_district": true, "margin_max": 10 },
      "chapters": [
        {
          "id": "c1",
          "bg": "station",
          "after_months": [1, 3],
          "lines": [
            { "speaker": "narrator", "text": "選挙から一月。朝の駅前に、見覚えのある顔があった。" },
            { "speaker": "rival", "text": "次は負けませんよ。この区のことは、私のほうが分かっている。" },
            { "speaker": "self", "text": "望むところです。" }
          ],
          "choices": [
            {
              "label": "握手を求める",
              "result": "{rival}は一瞬迷ってから手を握り返した。",
              "effects": { "bonds": { "rival": 10 }, "relations": { "press": 3 } },
              "flags": ["rival_handshake"],
              "next": "c2"
            },
            {
              "label": "黙って立ち去る",
              "result": "背中に視線を感じた。",
              "effects": { "bonds": { "rival": -10 } },
              "flags": ["rival_cold"],
              "next": "c2"
            }
          ]
        },
        {
          "id": "c2",
          "bg": "street",
          "after_months": [6, 12],
          "conditions": { "rival_in_district": true },
          "lines": [ { "speaker": "narrator", "text": "……" } ],
          "choices": [
            { "label": "……", "result": "……", "effects": {}, "next": "end_respect", "if_flags": ["rival_handshake"] },
            { "label": "……", "result": "……", "effects": {}, "next": "end_feud" }
          ]
        }
      ],
      "endings": [
        { "id": "end_respect", "title": "好敵手", "text": "結末の短い文（60字以内）", "effects": { "bond_state": { "rival": "好敵手" } } },
        { "id": "end_feud", "title": "因縁", "text": "……", "effects": { "bond_state": { "rival": "因縁" } } }
      ]
    }
  ],
  "rival_types": [],
  "bond_states": []
}
```

#### 物語の項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | 必須 | 英小文字とアンダースコアの一意な名前 |
| `title` | 必須 | 10字以内の題名 |
| `summary` | 必須 | 物語のあらすじ（80字以内。プレイヤーには見せない、取り込む人のための説明） |
| `cast` | 必須 | 出てくる人物（上の表の書き方の配列） |
| `start` | 必須 | 物語が始まる条件（下の「条件」）。`trigger` で始まる時を決める：`"monthly"`（毎月の終わりに条件を見る）、`"after_election"`（総選挙の結果のすぐあと）、`"first_win"`（初当選のすぐあと）、`"post_change"`（役職に就いた・外れたすぐあと） |
| `chapters` | 必須 | 章の配列。最初の章から始まる |
| `endings` | 必須 | 結末の配列（2つ以上） |
| `once` | 任意 | `false` なら一生に何度も起きうる。書かなければ一生に一度 |

#### 章の項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | 必須 | 物語の中で一意な名前 |
| `bg` | 必須 | 背景の場所。`office`（地元の事務所）、`campaign`（選挙事務所）、`station`（駅前）、`street`（商店街）、`hall`（公民館・集会所）、`diet`（国会の廊下・委員会室）、`party_hq`（党本部）、`ryotei`（料亭・会食の席）、`home`（自宅）、`hospital`（病院）、`disaster`（被災地）、`tv`（テレビ局・記者会見）のどれか |
| `after_months` | 必須 | 前の章から何か月あとに起きるか（最小と最大）。最初の章は始まる条件を満たしてから |
| `conditions` | 任意 | この章が起きる条件（下の「条件」）。最大の月を過ぎても満たされなければ、`fallback` の結末で終わる |
| `fallback` | 任意 | 条件を満たせなかったときの結末の id。書かなければ何も起きずに終わる |
| `lines` | 必須 | セリフの配列。`speaker` は上の登場人物の書き方、`text` はセリフ。`other` のときは `name` も書く。`face` に表情（`normal` `smile` `angry` `sad` `surprised` `serious`）を書いてよい |
| `choices` | 必須 | 選択肢を2〜3個 |

#### 選択肢の項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `label` | 必須 | 選択肢の文（20字以内） |
| `result` | 必須 | 選んだあとの結果（50字以内） |
| `effects` | 必須 | 効果（下の表）。何も起きないなら `{}` |
| `flags` | 任意 | 立てる旗（英小文字の配列） |
| `next` | 必須 | 次の章の id か、結末の id |
| `if_flags` | 任意 | この旗がすべて立っているときだけ出る選択肢 |
| `risk` | 任意 | 能力の判定。プレイヤーの能力 `ability`（`"弁舌"` `"政策"` `"調整"` `"知名度"` `"組織"` `"資金"`）が `threshold`（40〜75）未満なら、`fail_result`、`fail_effects`、`fail_next` になる |

#### 条件（start と conditions に書ける項目）

| 項目 | 内容 |
|---|---|
| `status` | `"候補"`（初当選前）、`"浪人"`（落選中）、`"議員"`（当選中）の配列 |
| `post` | `"minister"`（大臣・官房長官）、`"pm"`（首相）、`"party_exec"`（党三役）、`"leader"`（野党の党首）、`"opp_exec"`（野党の役職）、`"none"`（役職なし）の配列 |
| `ruling` | `true` なら自分の党が与党のとき、`false` なら野党のとき |
| `terms_min` / `terms_max` | 当選回数 |
| `age_min` / `age_max` | 年齢（始めは30〜50歳ほど） |
| `abilities` | 能力の下限。例：`{ "弁舌": 60 }` |
| `relations` | 集団との関係の下限。`secretary` `party` `supporters` `press` `kengi`（0〜100）。例：`{ "party": 60 }` |
| `bonds_min` / `bonds_max` | 人物との関係の下限と上限（-100〜100）。例：`{ "rival": 30 }` |
| `bond_state` | 人物の関係の札。例：`{ "rival": "因縁" }` |
| `jiban_min` | 地盤の下限（1〜4） |
| `skills` / `no_skills` | その特殊能力を持っている／持っていない（下の id の配列） |
| `flags` / `no_flags` | その旗が立っている／立っていない |
| `months` | その月だけ（1〜12 の配列） |
| `won_last` | `true` なら直前の総選挙で勝った、`false` なら負けた |
| `margin_max` | 直前の総選挙の自分とライバルの得票率の差（ポイント）がこれ以下 |
| `rival_in_district` | `true` ならライバルがまだ自分の区で出馬を続けている（引退や比例への転出をしていない） |

#### 効果（effects）の項目と目安

| 項目 | 意味 | 目安の幅 |
|---|---|---|
| `stamina` | 体力（上限100前後） | -20〜+20 |
| `mood` | やる気（1〜5の5段階） | -1 か +1 |
| `money` | 資金（万円） | -100〜+150 |
| `exp` | 経験点。`election`（選挙）、`policy`（政策）、`network`（人脈）、`media`（発信）、`money`（資金） | 1つにつき +4〜+25 |
| `relations` | 集団との関係 `secretary` `party` `supporters` `press` `kengi` | -10〜+10 |
| `bonds` | 人物との関係 `rival` `doki` `senpai` `secretary` | -25〜+25 |
| `bond_state` | 人物の関係の札を付ける。`好敵手` `因縁` `盟友` `師弟` `恩人` `不信` のどれか | 結末で使う |
| `jiban_progress` | 地盤の進み具合（1段上がるのに70〜200） | +5〜+40 |
| `abilities` | 能力の増減 `弁舌` `政策` `調整` `知名度` `組織` `資金`（1〜100） | ±1〜±4 |
| `approval` | 内閣支持率の増減（%）。役職に就いているときだけ | -3〜+2 |
| `vote_bonus` | 次の総選挙の自分の区の得票に足すポイント | -3〜+3 |
| `skills_add` / `skills_remove` | 特殊能力の付け外し（下の id の配列） | 1つ。結末で使う |

#### 特殊能力の id

金（強力）：`senkyo_kamisama`（選挙の神様）、`nemawashi_oni`（根回しの鬼）、`ronpa_ou`（論破王）。青（利点）：`dobuita`（ドブ板）、`tsuji_seppou`（辻説法）、`tairyoku_jiman`（体力自慢）、`hasshinryoku`（発信力）、`kengi_pipe`（県議とのパイプ）、`zaikai`（財界人脈）、`dandori`（段取り上手）、`genba_no_koe`（現場の声）。赤（欠点）：`shitsugen`（失言癖）、`enjou`（炎上体質）、`jimoto_fuzai`（地元不在）、`chousei_heta`（調整下手）、`kurou_shirazu`（苦労知らず）、`byoujaku`（病弱）。緑（両面）：`ippiki_ookami`（一匹狼）、`gekijougata`（劇場型）。

新しい特殊能力が物語に必要なら、`new_skills` に `{ "id", "name", "color", "description" }` の形で3つまで提案してよい。

### ライバルの人物像（rival_types）

ライバルは毎回、自動で作られる架空の議員がなる。その人物に当てはめる「型」を8種考えてほしい。1つの型は次の形。

```json
{
  "id": "local_veteran",
  "name": "地元一筋の古株",
  "description": "親の代からの地盤を持ち、祭りと葬式には必ず顔を出す。",
  "fits": "当選回数が多く、組織と地盤が強い議員",
  "catchphrase": "この町のことは、この町の人間が決める。",
  "lines": {
    "election_win": "（ライバルが勝ったときの一言）",
    "election_lose": "（ライバルが負けたときの一言）",
    "close_race": "（接戦のときの一言）",
    "好敵手": "（札が好敵手になったときの一言）",
    "因縁": "……",
    "盟友": "……",
    "不信": "……"
  }
}
```

`fits` は、どんな能力や経歴の議員に当てはめるかの説明（例：弁舌と知名度が高い、世襲、元官僚、元首長、若い新人）。8種がなるべく違う持ち味になるようにしてほしい。

### 関係の札の効果の案（bond_states）

`好敵手` `因縁` `盟友` `師弟` `恩人` `不信` の6つについて、ゲームの中でどんな効果を持たせるとよいかの案を出してほしい。効果に使えるのは、総選挙の票、毎月の経験点、集団との関係、党首選の票（同期や先輩が自分に入れるか）、出来事や物語の起きやすさ、能力の判定のしきい値。1つの札につき、効果を1〜3個と、その理由を1文。形は `{ "state": "好敵手", "effects": ["……"], "reason": "……" }`。

### ほしい数と内訳

物語を7本。

| 中心の人物 | 本数 | 題材の例 |
|---|---|---|
| ライバル | 2 | 同じ区で何度も戦う相手との因縁と和解、ライバルの不祥事や病気にどう向き合うか |
| 同期 | 1 | 同期の出世と失脚、党首選で敵味方に分かれる |
| 党の先輩 | 1 | 先輩の引退と、地盤や後援会を受け継ぐか |
| 秘書 | 1 | 秘書の独立（自分も出馬したい）、秘書の家族の事情 |
| 地元 | 1 | 地元の災害と復興、地元の大きな計画への賛否 |
| 自由に | 1 | 上にない題材（例：党の方針と地元の利益の板挟み、家族の病気） |

それぞれ3〜6章、結末は2〜3個。選択肢のうち4分の1ほどに `risk` を付けてください。

出力は、説明文を付けずに JSON のオブジェクトだけにしてください（```json のコードブロックで囲んでよい）。長くなる場合は、途中で切らずに、物語ごとに分けて続けて出してください。
