# 統合レポート：v0.0.6 検証と「連合」のまとめ

2026-11-17／対象：第8版レポート（v0.0.6-alpha 検証）と連合レポートの統合版
個別の数値の根拠は各レポートにあります。ここでは全体像だけをまとめます。

## 一行で言うと

連立の計算の作り直し（0.0.5）と連立の場面の追加（0.0.6）で、「中規模政党が政権に入れない」という当初の問題は解消し、「第一党を除いた連合による政権交代」も受動・能動の両方で起きるようになりました。残る課題は、連合の中心が集産党に偏ること、れいめいの党首に到達できないこと、そして小さい党が政権を率いると組閣で止まる不具合です。

## 壁の移動：0.0.3 → 0.0.5 → 0.0.6

| 段階 | 状態 |
|---|---|
| v0.0.3（465議席化） | 刷新・協和党は政権入り0/60。理由は連立の計算（距離の上限2.0、相手は近い順に最大2党、現職ブロックの継続優先）と特定済み |
| v0.0.5（計算の全面探索化） | 刷新55/60・協和党60/60が政権入り。ただし主導と首相は全党0のまま。壁は「第一党になれない」へ移動。第一党を除いた連合と任期途中の離脱も実装されたが、標準2人生では連合は観測されず |
| v0.0.6（連立の場面） | 公正党が首相9/30（方針1）まで到達。集産党は主導・首相29/30。刷新・協和党の主導はまだ1〜5/30で、「主導の壁」が最後に残りました |

## 連合についての結論

- 受動観察（v0.0.5、243人生・1,986総選挙）：第一党を除いた連合は55回、すべて民政党（166〜201議席）を除く民権党中心の3党連立（234〜250議席）で、55回とも連合の経路による政権交代でした
- 能動介入（v0.0.6、600人生）：場面の呼びかけで作る分が加わり、検出は総選挙の約7〜8%に。主導は民権党・集産党・公正党を中心に多様化し、6党連合や、8議席の集産党・1議席の社平党の党首が首相になる人生も生まれました
- 頻度は「30年の政治史で何度か起きる」水準で、連合ばかりになるような暴走はありません。政権交代そのものも平均2.7〜2.9回／30年、少数与党に終わる選挙は約3割、第一党の議席は160〜363の範囲で、政局の動きは過剰でも停滞でもありません

## v0.0.6 の場面の評価

- 3種の場面（誘い／首相の座／呼びかけ）は、提示文に組める顔ぶれと判定のヒントまで書かれていて、読んで選べます。協和党の人生で「加わる／閣外協力／断る」の3つとも、結果が提示どおりになることを確認しました
- 標準人生Aでは呼びかけ3回成功で通算約8年1か月の首相在任となり、連作の物語（「連立政権の岐路」など）と合わせて、政権を取る側の物語が成立しています
- 小さい点：呼びかけ（強硬）の文面が通常と同じで、与党が過半数の状況と語り手の文がずれる場面があります

## 残る課題（優先順）

1. **組閣で止まる不具合**：政権を率いる党の議員が足りないと「〜に就ける議員がいません」で処理が終了します。再現手順つきで確認済み、試行Aでは600人生中47人生（社平党・保守会議の人生に集中）。連合の目玉である「小さい党の首相」で起きるため、最優先の修正をおすすめします
2. **集産党の中心への偏り**：重み付き距離が最小の党が首相党になる計算で、座標の中央にいる集産党がほぼ常勝（方針1で主導29/30）。中心の判定に議席の条件を足すなどの調整候補です
3. **れいめいの党首に到達できない**：60人生で党首0回・幹事長止まり58回。他党と比べて際立っており、党首選の到達可能性の確認をおすすめします
4. **刷新・協和党の主導**：政権入りは安定しましたが主導・首相は1〜5/30。第一党を除いた連合の中心が「距離の中心」に寄る限り、中規模政党が主導する道は細いままです

## 検証の範囲と限界

- 数値は CLI（de417f5）での自動プレイによるもの。配布中の GUI は 060e4c8（物語31本）で、ゲームのコードは同一、クラッシュは 060e4c8 でも再現しました
- 旧セーブの互換は、形式3・形式2相当のデータをテストで読み込んで確認しました（GUI の実セーブでの確認はしていません）
- 政局ログの文面は CLI の応答に含まれないため、任期途中の構成変化の内訳（離脱／組み直し／場面による交代）は数え分けられていません
