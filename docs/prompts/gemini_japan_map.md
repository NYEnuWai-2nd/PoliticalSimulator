あなたは、ブラウザで動く政治シミュレーションゲーム用に、デフォルメした日本地図を JavaScript で作ります。選挙結果を都道府県ごとに色分けして表示するのに使います。以下の要件をすべて満たしてください。

## 地図の要件

1. デフォルメした日本地図にする。実際の海岸線や県境は再現しない。
2. ベクター形式（SVG）で描く。画像ファイルや外部の地図データは使わない。
3. 47都道府県をすべて含める。都道府県コードは JIS X 0401（北海道=1 〜 沖縄=47）を使う。
4. 都道府県同士の境界がはっきりわかるようにする。隣の県との境界線と、海岸線（陸と海の境）は線の太さか色で区別する。
5. 形は四角を組み合わせたものにする。すべての辺を水平か垂直にし、斜めの線は形に使わない。たとえば東京都は横長の長方形にする（西が多摩、東が23区）。例外は、沖縄県を本土から離れた位置に分けて描くための区切り線だけで、この線は海の上に引き、斜めにしてもよい。

## 作り方の指定（重要）

都道府県の形は、座標の多角形を手で書くのではなく、方眼（マス目）で定義してください。各マスにどの都道府県が入るかを文字列の配列で書き、そこから輪郭を自動で計算します。こうすると、辺が水平と垂直だけになり、隣り合う県の境界が必ずぴったり一致し、すき間や重なりが生まれません。あとから人が手で形を直すのも簡単になります。

方眼の書式：

```js
// 1マス = 2文字の都道府県コード。"00" は海。マスの間は半角空白1つで区切る
export const MAP_ROWS = [
  "00 00 00 01 01 01",
  "00 00 00 01 01 01",
  // ...
];
```

方眼について守ってほしいこと：

- 全体は横40〜50マス、縦40〜50マス程度にする。すべての行のマス数を揃える。
- 面積は実際の比にしなくてよい。どの県もクリックでき、県名のラベルが入る大きさにする。最小でも2×2マス（4マス）以上にする。北海道は大きめでよいが、陸のマス全体の1割程度までにする。
- 各県は一つにつながった形にする（上下左右でつながる。斜めだけの接続は不可）。穴や飛び地を作らない。
- 離島（佐渡、淡路島、伊豆諸島、小笠原、対馬、五島、奄美など）と北方領土は描かない。
- 本州と北海道、本州と四国、本州と九州の間には、1マス以上の海をはさむ。
- 位置関係は実際の日本に合わせる。北海道が右上、九州が左下になる階段状の配置にする。千葉県は東京都の東、神奈川県は東京都の南、埼玉県は東京都の北、山梨県は東京都の西に置く。
- 余裕があれば、能登半島、紀伊半島、房総半島、知床などの目立つ形を、マスの出っ張りで少しだけ表現してよい。
- 沖縄県は本土から離した位置（左上の日本海側の空いた場所、または右下の太平洋側の空いた場所）に置く。本土との間に区切り線を引く。この線は県の形の一部ではなく、別の SVG の線として描く。

## 出力してほしいファイル

### 1. `japanMap.js`（ES モジュール、外部ライブラリなし）

次のものを export してください。

- `PREFECTURES`：47件の配列。各要素は `{ code: 1, name: "北海道", label: "北海道", region: "北海道" }` の形。`label` は地図に表示する短い名前（「北海道」「青森」「東京」「大阪」のように「県」「府」「都」を省く。北海道はそのまま）。`region` は北海道、東北、関東、中部、近畿、中国、四国、九州・沖縄の8地方。
- `ADJACENCY`：上の隣接一覧をそのままデータにしたもの（`{ 1: [], 2: [3, 5], ... }`）。
- `MAP_ROWS`：方眼の定義。
- `buildMapGeometry()`：方眼から各県の輪郭を計算して返す関数。戻り値は `{ width, height, prefectures: [{ code, path, labelX, labelY }], coastPath, borderPath, okinawaSeparator }`。
  - `path` は SVG の `d` 属性に入れる文字列で、県の外周を表す。隣り合う同じ県のマスは一つの形に結合し、内部のマス目の線は出さない。
  - `labelX, labelY` はラベルを置く点で、必ずその県のマスの内側に入る点にする（重心が県の外に出る L 字形などに注意。県の中で最も大きい長方形の中心などを使う）。
  - `borderPath` は県と県の境界だけの線、`coastPath` は陸と海の境界だけの線。
  - `okinawaSeparator` は沖縄を分ける区切り線の座標（`{ x1, y1, x2, y2 }`）。
- `renderJapanMap(container, options)`：`container` の中に SVG を作って返す関数。`options` は次のとおり。
  - `cellSize`（1マスのピクセル数、既定は16）
  - `fill(code)`：県の塗り色を返す関数（既定は薄い灰色）
  - `showLabels`（既定は true）
  - `onClick(code, event)`、`onHover(code | null, event)`
  - SVG は `viewBox` を使い、親要素の幅に合わせて伸び縮みするようにする。
  - 各県の `<path>` には `data-code` 属性と `class="pref"` を付ける。マウスを乗せた県は少し強調する。
  - 境界線は `borderPath` を細めの線、`coastPath` を太めの線で、県の形の上に重ねて描く。
- `updateFills(svg, fill)`：作った SVG の塗り色だけを描き直す関数（選挙結果の更新に使う）。
- `validateMap()`：次を検査し、問題の一覧を返す関数。
  - すべての行のマス数が同じか
  - 1〜47のコードがすべて登場し、それ以外のコードがないか
  - 各県のマスが上下左右で一つにつながっているか
  - 各県が4マス以上あるか
  - 方眼から求めた隣接と `ADJACENCY` の違い（足りない組と余分な組）

### 2. `demo.html`

`japanMap.js` を読み込み、地方ごとに色分けした地図を表示する確認用のページ。県にマウスを乗せると県名を表示し、クリックした県名をページ内に表示する。ページを開いたときに `validateMap()` の結果をページ内に表示する。

## そのほかの指定

- コード中のコメントは日本語で書く。
- 1ファイルに収まらないほど長くなる場合も、方眼の定義（`MAP_ROWS`）は省略せず全行を出力する。「以下同様」などで省略しない。
- 最後に、意図して守らなかった隣接の組と、形を決めるときに迷った点を短く説明する。検査の結果はこちらで `validateMap()` を実行して確かめるので、検査に通ったと推測で書かなくてよい。
